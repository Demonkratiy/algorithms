# Sort Colors (Dutch National Flag)

**Тема:** sorting без сравнений / three pointers · **Сложность:** medium · **Приоритет:** 🔴 основная

## Условие

Дан массив `nums`, содержащий только числа `0`, `1` и `2` (красный, белый, синий).
Отсортируй его **на месте** так, чтобы все `0` шли первыми, затем `1`, затем `2`.

Встроенной сортировкой пользоваться нельзя. Цель — **один проход** и `O(1)` памяти.

## Примеры

```
Вход:  [2, 0, 2, 1, 1, 0]     Выход: [0, 0, 1, 1, 2, 2]
Вход:  [2, 0, 1]              Выход: [0, 1, 2]
Вход:  [0]                    Выход: [0]
Вход:  [2, 2]                 Выход: [2, 2]
```

## Ограничения

- `1 <= nums.length <= 300`
- `nums[i]` ∈ `{0, 1, 2}`

## 🎯 Цель по сложности

- Время **`O(N)`** за **один проход**, память `O(1)`.
- Промежуточный вариант (тоже верный, но слабее): counting sort в два прохода — посчитать
  количество нулей/единиц/двоек, затем перезаписать массив. `O(N)` время, `O(1)` память, но
  **два прохода**. Интервьюер обычно просит «а можно за один?»

## 🧠 Ментальная модель

Три указателя делят массив на четыре зоны:

```
[0 0 0 | 1 1 1 | ? ? ? ? | 2 2 2]
        ↑       ↑        ↑
       low     mid      high
```

- `[0, low)` — уже разложенные нули;
- `[low, mid)` — единицы;
- `[mid, high]` — **неизвестная** зона, её и обрабатываем;
- `(high, n-1]` — двойки.

Алгоритм: смотрим на `nums[mid]`.
- `0` → меняем с `nums[low]`, `low++`, `mid++`;
- `1` → на месте, просто `mid++`;
- `2` → меняем с `nums[high]`, `high--`, **`mid` НЕ двигаем**.

## ⚠️ Подводные камни именно этой задачи

1. **При обмене с `high` нельзя увеличивать `mid`.** Элемент, пришедший справа, **ещё не
   просмотрен** — он может оказаться нулём. Если сдвинуть `mid`, ноль останется в середине.
   Это **главная ошибка** задачи; проверь на `[2, 0, 1]`.
2. **При обмене с `low` увеличивать `mid` можно.** Оттуда придёт либо `1` (уже обработанная
   зона), либо тот же элемент — в любом случае не `2`, и повторная проверка не нужна.
3. **Условие цикла `while (mid <= high)`** — нестрогое. При `mid === high` остаётся один
   непросмотренный элемент, его нужно обработать.
4. **Обмен в JS.** `[a[i], a[j]] = [a[j], a[i]]` работает; главное — не написать
   `a[i] = a[j]; a[j] = a[i];` (потеря значения).
5. Массивы вроде `[2,2,2]` или `[0,0,0]` — проверь, что нет бесконечного цикла.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение (один проход) + объяснение</summary>

```js
function sortColors(nums) {
  let low = 0;                       // граница нулей
  let mid = 0;                       // текущий рассматриваемый
  let high = nums.length - 1;        // граница двоек

  while (mid <= high) {
    if (nums[mid] === 0) {
      [nums[low], nums[mid]] = [nums[mid], nums[low]];
      low++;
      mid++;                         // пришедший слева уже обработан
    } else if (nums[mid] === 1) {
      mid++;                         // единица уже на своём месте
    } else {                         // nums[mid] === 2
      [nums[mid], nums[high]] = [nums[high], nums[mid]];
      high--;
      // mid НЕ увеличиваем — пришедший справа элемент ещё не просмотрен
    }
  }
}
```

**Трассировка** `[2, 0, 2, 1, 1, 0]`:

| шаг | low | mid | high | массив | действие |
|:---:|:---:|:---:|:----:|--------|---|
| старт | 0 | 0 | 5 | `[2,0,2,1,1,0]` | `nums[0]=2` → swap с high |
| 1 | 0 | 0 | 4 | `[0,0,2,1,1,2]` | `nums[0]=0` → swap с low, оба++ |
| 2 | 1 | 1 | 4 | `[0,0,2,1,1,2]` | `nums[1]=0` → swap (сам с собой), оба++ |
| 3 | 2 | 2 | 4 | `[0,0,2,1,1,2]` | `nums[2]=2` → swap с high, high-- |
| 4 | 2 | 2 | 3 | `[0,0,1,1,2,2]` | `nums[2]=1` → mid++ |
| 5 | 2 | 3 | 3 | `[0,0,1,1,2,2]` | `nums[3]=1` → mid++ |
| 6 | 2 | 4 | 3 | — | `mid > high` → выход |

Результат `[0,0,1,1,2,2]` ✅

**Проверка «почему mid не двигается при двойке»** на `[2, 0, 1]`:
шаг 1: `nums[0] = 2` → swap с `high=2` → `[1, 0, 2]`, `high = 1`, `mid = 0`.
Если бы мы сдвинули `mid`, единица на позиции 0 осталась бы перед нулём → `[1, 0, 2]` ❌
Не сдвигая: `nums[0] = 1` → `mid = 1`; `nums[1] = 0` → swap с `low=0` → `[0, 1, 2]` ✅

**Сложность:** время `O(N)` — `mid` и `high` суммарно проходят массив один раз.
Память `O(1)` — три индекса.

</details>

<details>
<summary>Counting sort (два прохода) — тоже принимается</summary>

```js
function sortColorsCounting(nums) {
  const counts = [0, 0, 0];
  for (const n of nums) counts[n]++;          // проход 1: подсчёт

  let i = 0;
  for (let color = 0; color < 3; color++) {   // проход 2: перезапись
    for (let c = 0; c < counts[color]; c++) nums[i++] = color;
  }
}
```

`O(N)` время, `O(1)` память (массив из 3 счётчиков — константа). Проще для рассуждения, но
**два прохода** и он «переписывает» данные, что не всегда допустимо (например, если элементы —
объекты с дополнительными полями, а не просто числа). Обязательно проговори это отличие.

</details>
