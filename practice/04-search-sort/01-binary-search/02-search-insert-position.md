# Search Insert Position

**Тема:** binary-search (переход к поиску границы) · **Сложность:** easy · **Приоритет:** 🔴 основная

## Условие

Дан отсортированный массив `nums` без дубликатов и число `target`.
Верни индекс `target`, если он есть. Если нет — верни индекс, **куда его нужно вставить**,
чтобы массив остался отсортированным.

Требуется `O(log N)`.

## Примеры

```
Вход:  nums = [1, 3, 5, 6], target = 5     Выход: 2
Вход:  nums = [1, 3, 5, 6], target = 2     Выход: 1
Вход:  nums = [1, 3, 5, 6], target = 7     Выход: 4    ← за концом массива
Вход:  nums = [1, 3, 5, 6], target = 0     Выход: 0
```

## Ограничения

- `1 <= nums.length <= 10^4`
- значения уникальны, массив отсортирован.

## 🎯 Цель по сложности

- Время `O(log N)`, память `O(1)`.

## 🧠 Ментальная модель

Это уже **не поиск значения, а поиск границы**: нужен первый индекс, где `nums[i] >= target`.

```
nums:            [1, 3, 5, 6]      target = 2
nums[i] >= 2:     ✗  ✓  ✓  ✓
                     ↑ ответ 1
```

Заметь красивое свойство: если `target` **есть** в массиве, первый `nums[i] >= target` — это и
есть его индекс. Одна формулировка покрывает оба случая условия, никаких `if` не нужно.

Задача — мостик от классического шаблона к шаблону границы. Можно решить обоими способами;
полезно написать **оба** и понять разницу.

## ⚠️ Подводные камни именно этой задачи

1. **Ответ может быть равен `nums.length`** (когда `target` больше всех). Значит, в шаблоне
   границы `right` инициализируется как `nums.length`, а **не** `length - 1` — иначе этот ответ
   недостижим.
2. **Шаблон границы: `while (left < right)` и `right = mid` (без `-1`).** Если смешать с
   классическим (`left <= right` + `right = mid`) — получишь **бесконечный цикл**.
3. **Что возвращать в классическом варианте.** Если решаешь через `while (left <= right)`, то
   после выхода из цикла ответом является `left` — но это надо **понимать**, а не запоминать:
   при выходе `left` указывает ровно на первую позицию, где элемент не меньше `target`.
4. Не путай «вставить перед» и «вставить после» при равенстве. Условие требует индекс самого
   элемента, значит сравнение `>=`, а не `>`.

```js
let left = 0, right = nums.length;      // ИСКЛЮЧИТЕЛЬНАЯ граница
while (left < right) {
  const mid = Math.floor((left + right) / 2);
  if (nums[mid] >= target) right = mid;   // кандидат — не отбрасываем
  else left = mid + 1;
}
return left;
```

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение шаблоном границы (рекомендуемое)</summary>

```js
function searchInsert(nums, target) {
  let left = 0;
  let right = nums.length;          // исключительная граница: ответ может быть length

  while (left < right) {
    const mid = Math.floor((left + right) / 2);

    if (nums[mid] >= target) {
      right = mid;                  // mid подходит, но, может быть, есть левее
    } else {
      left = mid + 1;               // mid точно не подходит
    }
  }

  return left;                      // left === right — искомая граница
}
```

**Инвариант, который стоит проговаривать:** в любой момент ответ лежит в `[left, right]`.
Слева от `left` все элементы `< target`, справа от `right` — все `>= target`.
Цикл сужает этот отрезок, пока он не схлопнется в одну точку.

**Трассировка** `nums = [1, 3, 5, 6]`, `target = 2`:

| шаг | left | right | mid | nums[mid] | ветка |
|:---:|:----:|:-----:|:---:|:---------:|---|
| 1 | 0 | 4 | 2 | 5 | `5 >= 2` → right = 2 |
| 2 | 0 | 2 | 1 | 3 | `3 >= 2` → right = 1 |
| 3 | 0 | 1 | 0 | 1 | `1 < 2` → left = 1 |
| 4 | left === right = 1 → выход | | | | ответ **1** ✅ |

**Трассировка** `target = 7`:

| шаг | left | right | mid | nums[mid] | ветка |
|:---:|:----:|:-----:|:---:|:---------:|---|
| 1 | 0 | 4 | 2 | 5 | `5 < 7` → left = 3 |
| 2 | 3 | 4 | 3 | 6 | `6 < 7` → left = 4 |
| 3 | left === right = 4 → выход | | | | ответ **4** ✅ (за концом) |

**Сложность:** время `O(log N)`, память `O(1)`.

</details>

<details>
<summary>Решение классическим шаблоном (тоже верное)</summary>

```js
function searchInsertClassic(nums, target) {
  let left = 0;
  let right = nums.length - 1;

  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
  }

  return left;      // ключевой момент: НЕ -1, а left
}
```

**Почему в конце именно `left`.** Цикл заканчивается, когда `left > right`, причём они
расходятся ровно на единицу: `right = left - 1`. По инварианту всё слева от `left` строго
меньше `target`, а `left` — первая позиция, куда `target` можно поставить. Проверь на
`nums = [1, 3, 5, 6], target = 7`: цикл закончится с `left = 4`, `right = 3` → ответ `4` ✅

Оба решения `O(log N)`. Шаблон границы предпочтительнее тем, что обобщается на дубликаты и на
«бинарный поиск по ответу».

</details>
