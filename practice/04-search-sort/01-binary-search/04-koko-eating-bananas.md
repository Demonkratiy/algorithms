# Koko Eating Bananas (бинарный поиск по ответу)

**Тема:** binary-search по ответу · **Сложность:** medium · **Приоритет:** 🔴 основная

> **Самая важная задача темы.** Здесь нет отсортированного массива — сортировано *пространство
> ответов*. Освоив этот приём, ты сможешь решать целое семейство задач, которые «не выглядят»
> как бинарный поиск.

## Условие

Коко ест бананы. Есть `piles` — массив куч, `piles[i]` бананов в `i`-й куче. Сторож вернётся
через `h` часов.

Коко выбирает **скорость `k`** (бананов в час). Каждый час она выбирает одну кучу и съедает из
неё `k` бананов. Если в куче осталось меньше `k` — она съедает всё и **этот час больше не ест**
(к следующей куче в тот же час не переходит).

Верни **минимальную** скорость `k`, при которой Коко успеет съесть все бананы за `h` часов.

## Примеры

```
Вход:  piles = [3, 6, 7, 11], h = 8      Выход: 4
Вход:  piles = [30, 11, 23, 4, 20], h = 5    Выход: 30
Вход:  piles = [30, 11, 23, 4, 20], h = 6    Выход: 23
```

Разбор первого: при `k = 4` часы = ⌈3/4⌉ + ⌈6/4⌉ + ⌈7/4⌉ + ⌈11/4⌉ = 1 + 2 + 2 + 3 = 8 ≤ 8 ✅
При `k = 3`: 1 + 2 + 3 + 4 = 10 > 8 ❌

## Ограничения

- `1 <= piles.length <= 10^4`
- `piles.length <= h <= 10^9`
- `1 <= piles[i] <= 10^9`

## 🎯 Цель по сложности

- Время **`O(N log M)`**, где `N = piles.length`, `M = max(piles)`.
- Память `O(1)`.
- Перебор всех `k` от 1 до `10^9` с проверкой `O(N)` → `O(N·M)` — безнадёжно.

## 🧠 Ментальная модель

Задай себе два вопроса — это **универсальный чек-лист** для «поиска по ответу»:

**1. Каков диапазон возможных ответов?**
От `1` (минимальная осмысленная скорость) до `max(piles)` (быстрее нет смысла: за час съедается
максимум одна куча целиком).

**2. Монотонно ли свойство «успевает»?**
Да: если Коко успевает при скорости `k`, то при `k + 1` она успевает тем более. Значит:

```
k:          1   2   3   4   5   6   7
успевает:   ✗   ✗   ✗   ✓   ✓   ✓   ✓
                        ↑ ищем эту границу — это и есть ответ
```

Раз пространство ответов монотонно — ищем границу бинарно. Проверка кандидата:

```js
function hoursNeeded(piles, k) {
  let hours = 0;
  for (const pile of piles) hours += Math.ceil(pile / k);
  return hours;
}
```

## ⚠️ Подводные камни именно этой задачи

1. **`Math.ceil`, а не деление нацело.** Куча из 7 бананов при `k = 4` съедается за **2** часа
   (второй час — неполный, но час потрачен). `7 / 4 = 1.75` → `Math.ceil` → `2`.
   Забыть округление вверх — самая частая ошибка.
2. **`left = 1`, а не `0`.** Скорость `0` бессмысленна и даёт деление на ноль → `Infinity`.
3. **`right = Math.max(...piles)`.** Больший `k` не улучшает результат: съесть больше одной кучи
   за час нельзя. Взять `right = 10^9` тоже сработает (просто чуть больше итераций), но лучше
   объяснить точную границу.
   ⚠️ `Math.max(...piles)` со спредом на массиве в `10^4` элементов допустим, но на очень
   больших массивах (`>10^5`) может вызвать `RangeError` — тогда считай максимум циклом.
4. **Шаблон границы, а не классический.** Ищем минимальный подходящий → `while (left < right)`,
   `right = mid` при успехе, `left = mid + 1` при неудаче, ответ — `left`.
5. **Сложность считается с учётом проверки.** Не `O(log M)`, а `O(N log M)`: каждая из `log M`
   итераций делает проход `O(N)`. На интервью назови именно так.

<details>
<summary>Решение + объяснение</summary>

```js
function minEatingSpeed(piles, h) {
  const canFinish = (k) => {
    let hours = 0;
    for (const pile of piles) {
      hours += Math.ceil(pile / k);        // неполный час всё равно считается целым
      if (hours > h) return false;         // ранний выход — небольшая оптимизация
    }
    return hours <= h;
  };

  let left = 1;
  let right = Math.max(...piles);

  while (left < right) {
    const mid = Math.floor((left + right) / 2);
    if (canFinish(mid)) {
      right = mid;          // mid подходит — но, возможно, есть меньше
    } else {
      left = mid + 1;       // mid не подходит — точно нужно больше
    }
  }

  return left;
}
```

**Трассировка** `piles = [3, 6, 7, 11]`, `h = 8`, диапазон `[1, 11]`:

| шаг | left | right | mid | часы при mid | успевает? | действие |
|:---:|:----:|:-----:|:---:|:------------:|:---------:|---|
| 1 | 1 | 11 | 6 | 1+1+2+2 = 6 | да | right = 6 |
| 2 | 1 | 6 | 3 | 1+2+3+4 = 10 | нет | left = 4 |
| 3 | 4 | 6 | 5 | 1+2+2+3 = 8 | да | right = 5 |
| 4 | 4 | 5 | 4 | 1+2+2+3 = 8 | да | right = 4 |
| 5 | left === right = 4 → ответ **4** ✅ | | | | | |

**Сложность:** время `O(N log M)` — `log₂(11) ≈ 4` итерации, каждая с проходом по массиву.
При `M = 10^9` это ~30 итераций. Память `O(1)`.

</details>

<details>
<summary>Шаблон «бинарный поиск по ответу» — выучи его, а не задачу</summary>

```js
// 1. Определи диапазон ответов [lo, hi]
// 2. Напиши предикат isFeasible(x) — подходит ли кандидат
// 3. Убедись, что предикат МОНОТОНЕН (✗✗✗✓✓✓ или ✓✓✓✗✗✗)
// 4. Примени шаблон границы

let left = lo, right = hi;
while (left < right) {
  const mid = Math.floor((left + right) / 2);
  if (isFeasible(mid)) right = mid;    // ищем МИНИМАЛЬНЫЙ подходящий
  else left = mid + 1;
}
return left;
```

Для **максимального** подходящего (когда ✓✓✓✗✗✗) шаблон зеркальный:
`mid = Math.ceil((left + right) / 2)` (округление вверх, чтобы не зациклиться), при успехе
`left = mid`, иначе `right = mid - 1`.

**Задачи этого семейства** (все решаются одним шаблоном, меняется только `isFeasible`):
- Koko Eating Bananas — минимальная скорость;
- Capacity to Ship Packages Within D Days — минимальная грузоподъёмность;
- Split Array Largest Sum — минимальная из максимальных сумм частей;
- Minimum Number of Days to Make m Bouquets;
- Find the Smallest Divisor Given a Threshold;
- Sqrt(x) — целочисленный корень (см. [`06-sqrt`](06-sqrt.md)).

Узнаваемый маркер в условии: **«минимальное/максимальное значение, при котором выполняется
условие»** + «проверить конкретное значение легко».

</details>

<details>
<summary>Как это объяснять на интервью</summary>

> _«Прямого перебора k от 1 до 10^9 не хватит по времени. Но заметьте: если скорость k
> подходит, то любая большая тоже подходит — свойство монотонно. Значит, я могу искать границу
> бинарным поиском по диапазону скоростей [1, max(piles)], а проверку "успевает ли" делать за
> O(N). Итого O(N log M)»._

Именно такая формулировка — «монотонность → бинарный поиск по ответу» — то, что оценивается
выше всего в этой задаче.

</details>
