# Lowest Common Ancestor (наименьший общий предок)

**Тема:** binary-trees (DFS, post-order) · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

## Условие

**Часть A (BST, easy).** Дан корень **binary search tree** и два узла `p` и `q`.
Найди их наименьшего общего предка (LCA) — самый глубокий узел, который является предком
обоих. Узел считается предком **самого себя**.

**Часть B (обычное дерево, medium).** То же, но дерево — обычное бинарное, без свойства BST.

Гарантируется, что оба узла присутствуют в дереве и все значения уникальны.

## Примеры

```
        6                    Часть A (BST):
      /   \                    LCA(2, 8) = 6
     2     8                   LCA(2, 4) = 2   ← узел является предком самого себя
    / \   / \
   0   4 7   9
      / \
     3   5

        3                    Часть B (обычное дерево):
      /   \                    LCA(5, 1) = 3
     5     1                   LCA(5, 4) = 5
    / \   / \
   6   2 0   8
      / \
     7   4
```

## Ограничения

- `2 <= число узлов <= 10^5`
- значения уникальны, `p !== q`, оба присутствуют в дереве.

## 🎯 Цель по сложности

- Часть A (BST): время **`O(h)`**, память `O(1)` итеративно.
- Часть B (обычное): время `O(N)`, память `O(h)`.

## 🧠 Ментальная модель

**Часть A — используем свойство BST.** Начиная с корня:
- если **оба** значения меньше текущего → LCA точно в левом поддереве;
- если **оба** больше → в правом;
- иначе (значения «разошлись» или одно равно текущему) → **текущий узел и есть LCA**.

Точка расхождения — это и есть ответ. Спускаться дальше не нужно.

**Часть B — «сигнал снизу вверх».** Свойства BST нет, поэтому обходим всё дерево:

```js
if (node === null) return null;
if (node === p || node === q) return node;      // нашли одного — сигналим наверх

const left = lca(node.left);
const right = lca(node.right);

if (left && right) return node;                 // p и q в РАЗНЫХ поддеревьях → это LCA
return left ?? right;                            // оба (или один) в одной стороне
```

Идея: каждый узел «докладывает» родителю, нашёл ли он кого-то из искомых. Узел, к которому
сигналы пришли **с обеих сторон**, — и есть LCA.

## ⚠️ Подводные камни этих задач

1. **Часть B: узел является предком самого себя.** Если `p` — предок `q`, ответ `p`.
   Строка `if (node === p || node === q) return node;` обрабатывает это автоматически — мы
   не спускаемся глубже. Многие пытаются добавить лишние проверки и ломают логику.
2. **Сравнивать ссылки на узлы, а не значения** (`node === p`), если по условию даны узлы.
   Если даны значения — сравнивай `node.val === p`. Прочитай условие внимательно.
3. **Часть A: не забыть случай `node.val === p.val`.** Условие на спуск влево должно быть
   строгим с обеих сторон: `p.val < node.val && q.val < node.val`.
4. **Часть B возвращает узел, а не `true`/`false`.** Возврат самого узла — то, что позволяет
   «протолкнуть» ответ наверх без дополнительных структур.
5. `left ?? right` (или `left || right`) в конце: если сигнал пришёл только с одной стороны,
   передаём его дальше вверх без изменений.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Часть A — BST</summary>

```js
function lowestCommonAncestorBST(root, p, q) {
  let node = root;

  while (node !== null) {
    if (p.val < node.val && q.val < node.val) {
      node = node.left;                 // оба слева
    } else if (p.val > node.val && q.val > node.val) {
      node = node.right;                // оба справа
    } else {
      return node;                      // разошлись (или один совпал) → LCA
    }
  }

  return null;
}
```

**Трассировка** `LCA(2, 8)` в BST из примера:
- узел `6`: `2 < 6`, но `8 > 6` → разошлись → **вернуть 6** ✅

**Трассировка** `LCA(2, 4)`:
- узел `6`: оба (`2`, `4`) меньше `6` → идём влево;
- узел `2`: `p.val === node.val` → ни одно из условий не выполнено → **вернуть 2** ✅
  (узел — предок самого себя).

**Сложность:** время `O(h)` — спускаемся по одному пути; `O(log N)` для сбалансированного BST.
Память `O(1)` — итеративно, без рекурсии.

</details>

<details>
<summary>Часть B — обычное дерево</summary>

```js
function lowestCommonAncestor(root, p, q) {
  if (root === null) return null;
  if (root === p || root === q) return root;      // нашли — сигналим наверх, глубже не идём

  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);

  if (left !== null && right !== null) return root;   // сигналы с ОБЕИХ сторон → это LCA

  return left !== null ? left : right;                 // передаём единственный сигнал вверх
}
```

**Трассировка** `LCA(5, 4)` для дерева:
```
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```

| узел | что происходит |
|---|---|
| `3` | не `p`/`q` → рекурсия в обе стороны |
| `5` | **это `p`** → возвращаем `5` наверх, в поддерево не спускаемся |
| `1` | не `p`/`q`; потомки `0` и `8` вернут `null` → возвращает `null` |
| `3` | `left = 5`, `right = null` → возвращает `5` ✅ |

Обрати внимание: `4` вообще не был найден — и это правильно. Раз `p = 5` является предком
`q = 4`, ответ `5`, и спускаться дальше не нужно. Именно ранний `return root` даёт это
бесплатно.

**Трассировка** `LCA(5, 1)`:
`3` получает `left = 5` и `right = 1` — сигналы с обеих сторон → возвращает `3` ✅

**Сложность:** время `O(N)` — в худшем случае обходим всё дерево. Память `O(h)` — стек.

</details>

<details>
<summary>Почему часть B работает — рассуждение для интервью</summary>

> _«Функция возвращает: null, если в поддереве нет ни p, ни q; сам узел p или q, если найден
> один из них; и LCA, если найдены оба. Три случая покрываются одним кодом, потому что как
> только сигналы приходят с обеих сторон, текущий узел по определению является наименьшим
> общим предком — ниже него они уже разошлись»._

Это пример **post-order** обхода: узел принимает решение **после** того, как получил ответы от
потомков. Сравни с Validate BST, где информация передавалась **вниз** (pre-order, диапазоны).
Умение выбрать направление потока информации — сверху вниз или снизу вверх — ключевой навык в
задачах на деревья.

</details>
