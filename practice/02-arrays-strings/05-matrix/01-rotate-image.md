# Rotate Image (поворот матрицы на 90°)

**Тема:** matrix · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

## Условие

Дана квадратная матрица `n × n`. Поверни её на **90° по часовой стрелке**, **на месте**
(без создания новой матрицы).

## Примеры

```
Вход:  [[1,2,3],        Выход: [[7,4,1],
        [4,5,6],                [8,5,2],
        [7,8,9]]                [9,6,3]]

Вход:  [[1,2],          Выход: [[3,1],
        [3,4]]                  [4,2]]

Вход:  [[1]]            Выход: [[1]]
```

## Ограничения

- `1 <= n <= 20`
- матрица **квадратная**.

## 🎯 Цель по сложности

- Время `O(n²)` (нужно тронуть каждый элемент), память **`O(1)`** — на месте.
- Решение через новую матрицу тоже верное, но `O(n²)` памяти — условие просит на месте.

## 🧠 Ментальная модель

Поворот на 90° по часовой = **транспонирование** + **разворот каждой строки**:

```
1 2 3     транспонируем     1 4 7     разворот строк     7 4 1
4 5 6     ─────────────→    2 5 8     ──────────────→    8 5 2
7 8 9                       3 6 9                        9 6 3
```

**Транспонирование** — отражение относительно главной диагонали: `matrix[r][c] ↔ matrix[c][r]`.
**Разворот строки** — два указателя навстречу (тот самый Two Pointers).

Проверь себя: против часовой стрелки — те же две операции, но **в обратном порядке**
(сначала развернуть строки, потом транспонировать).

## ⚠️ Подводные камни именно этой задачи

1. **Внутренний цикл транспонирования начинается с `c = r + 1`.** При `c = 0` каждая пара
   поменяется дважды, и матрица вернётся к исходному виду. Это **главная ловушка** — проверь на
   `[[1,2],[3,4]]`: с `c = 0` получишь исходную матрицу.
2. **Обмен через деструктуризацию.** `a[r][c] = a[c][r]; a[c][r] = a[r][c];` теряет значение.
3. **Порядок операций.** Транспонирование **потом** разворот — для по часовой. Перепутаешь —
   получишь поворот против часовой.
4. **`reverse()` мутирует** массив и работает на месте — это здесь плюс, но помни о побочном
   эффекте в других задачах.
5. Матрица `1 × 1` — оба цикла не выполнятся, ответ верный. Проверь, что код не падает.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение + объяснение</summary>

```js
function rotate(matrix) {
  const n = matrix.length;

  // 1. транспонирование: только верхний треугольник
  for (let r = 0; r < n; r++) {
    for (let c = r + 1; c < n; c++) {
      [matrix[r][c], matrix[c][r]] = [matrix[c][r], matrix[r][c]];
    }
  }

  // 2. разворот каждой строки
  for (const row of matrix) {
    row.reverse();
  }
}
```

**Трассировка** `[[1,2,3],[4,5,6],[7,8,9]]`:

Транспонирование — какие пары меняются (только `c > r`):
`(0,1)↔(1,0)`, `(0,2)↔(2,0)`, `(1,2)↔(2,1)`. Диагональ `(0,0)`, `(1,1)`, `(2,2)` не трогаем.

```
после транспонирования:   после разворота строк:
1 4 7                     7 4 1
2 5 8                     8 5 2
3 6 9                     9 6 3   ✅
```

**Почему `c = r + 1`.** Пара `(0,1)` и `(1,0)` — это один и тот же обмен. Если пройти всю
матрицу, мы сначала поменяем их при `r=0, c=1`, а потом обратно при `r=1, c=0`. Верхний
треугольник гарантирует ровно один обмен на пару.

**Сложность:** время `O(n²)` — транспонирование трогает ~`n²/2` пар, разворот ещё `n²/2`
обменов. Память `O(1)` — всё на месте.

</details>

<details>
<summary>Альтернатива: поворот «кольцами»</summary>

```js
function rotateRings(matrix) {
  const n = matrix.length;

  for (let layer = 0; layer < Math.floor(n / 2); layer++) {
    const first = layer;
    const last = n - 1 - layer;

    for (let i = first; i < last; i++) {
      const offset = i - first;
      const top = matrix[first][i];                      // сохраняем верхний

      matrix[first][i] = matrix[last - offset][first];   // левый → верхний
      matrix[last - offset][first] = matrix[last][last - offset];  // нижний → левый
      matrix[last][last - offset] = matrix[i][last];     // правый → нижний
      matrix[i][last] = top;                             // верхний → правый
    }
  }
}
```

Классическое «книжное» решение: за один проход крутим по четыре элемента. Работает за тот же
`O(n²)`/`O(1)`, но индексы легко перепутать под давлением интервью.

**Совет:** на собеседовании выбирай вариант «транспонирование + разворот» — его проще
объяснить и почти невозможно ошибиться. Про кольца достаточно упомянуть, что такой способ
существует.

</details>

<details>
<summary>Против часовой стрелки и на 180°</summary>

```js
// против часовой: сначала развернуть строки, потом транспонировать
function rotateCounterClockwise(matrix) {
  for (const row of matrix) row.reverse();

  const n = matrix.length;
  for (let r = 0; r < n; r++) {
    for (let c = r + 1; c < n; c++) {
      [matrix[r][c], matrix[c][r]] = [matrix[c][r], matrix[r][c]];
    }
  }
}

// на 180°: развернуть порядок строк и каждую строку
function rotate180(matrix) {
  matrix.reverse();
  for (const row of matrix) row.reverse();
}
```

Полезно проговорить связь: **порядок двух операций определяет направление поворота**. Это
хорошая проверка того, что ты понял механику, а не заучил последовательность.

</details>
