# Group Anagrams

**Тема:** frequency-counter (Map + составной ключ) · **Сложность:** medium

## Условие
Дан массив строк `strs`. Сгруппируй строки, которые являются **анаграммами** друг друга
(состоят из одних и тех же символов в одинаковом количестве). Верни массив групп.

Порядок групп и порядок строк внутри группы — **любой** (не важен для проверки).

## Примеры
```
Вход:  strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
Выход: [["eat","tea","ate"], ["tan","nat"], ["bat"]]

Вход:  strs = [""]
Выход: [[""]]

Вход:  strs = ["a"]
Выход: [["a"]]
```

## Ограничения
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` состоит из строчных латинских букв.

## 🎯 Цель по сложности
- Время: `O(N * K)` или `O(N * K log K)` (N — число строк, K — макс. длина строки) — зависит
  от того, как строишь ключ (частотная подпись vs сортировка).
- Память: `O(N * K)` — храним все строки в группах.

## 🧠 Ментальная модель (Map с «ключом-подписью»)
Ключевая идея: у всех анаграмм должна быть **одинаковая "подпись" (canonical key)**. Строим
`Map`, где **ключ — подпись**, а **значение — массив строк** с этой подписью.

Два способа получить подпись строки:

1. **Сортировка символов** (проще): `"eat"` → `"aet"`, `"tea"` → `"aet"`. Одинаковая
   отсортированная строка = анаграммы. Ключ = `word.split('').sort().join('')`.
   Стоимость подписи одной строки — `O(K log K)`.

2. **Частотная подпись** (быстрее): посчитать частоты 26 букв и сделать из них строку, напр.
   `"a1e1t1..."` или массив из 26 чисел. Стоимость — `O(K)`, без `log`.

Начни со способа 1 (нагляднее), про способ 2 упомяни вслух как оптимизацию.

Алгоритм:
- для каждой строки посчитай её подпись;
- если подписи ещё нет в Map — заведи пустой массив;
- добавь строку в массив по этой подписи;
- в конце верни все значения Map.

## ✍️ Моё решение

Вход:  strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
Выход: [["eat","tea","ate"], ["tan","nat"], ["bat"]]

```js
function groupAnagrams(strs) {
  const groups = new Map();

  for (const word of strs){
    const key = word.split('').sort().join('');
    if (!groups.has(key)) {
      groups.set(key, []);
    }
    groups.get(key).push(word)
  }

  // const res = [];
  // for(const [key, value] of groups) {
  //   res.push(value);
  // }

  // return res;

  return [...groups.values()];
}
```

Время: O(N * K log K) · Память: O(N*K)
