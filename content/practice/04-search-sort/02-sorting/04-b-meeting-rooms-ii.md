# Meeting Rooms II

**Тема:** sorting + интервалы · **Приоритет:** ⚪ дополнительная · **Сложность:** medium

В [Meeting Rooms I](04-meeting-rooms.md) проверялась возможность посетить всё одному человеку. Здесь результат — число комнат.

## Условие

Дан массив интервалов `intervals[i] = [start, end]`. Верни **минимальное число переговорок**, необходимое для всех встреч.

Встречи `[1, 5]` и `[5, 8]` не конфликтуют: касание границ разрешено.

`0 <= intervals.length <= 10^4`, `0 <= start < end <= 10^6`.

Примеры: `[[0,30],[5,10],[15,20]] → 2`, `[[7,10],[2,4]] → 1`, `[[1,5],[5,8]] → 1`, `[] → 0`.

## 🎯 Цель по сложности

Время `O(N log N)`, память `O(N)`.

## 🧠 Ментальная модель

** приём «два отсортированных массива событий».**
Разделяем начала и концы и сортируем их **независимо**:

```
starts: [0, 5, 15]
ends:   [10, 20, 30]
```

Идём по началам. Если очередное начало раньше самого раннего свободного конца — нужна **новая**
комната. Иначе комната освободилась — переиспользуем её и двигаем указатель по концам.

```
start=0  vs end=10 → 0 < 10  → нужна комната, rooms = 1
start=5  vs end=10 → 5 < 10  → нужна комната, rooms = 2
start=15 vs end=10 → 15 >= 10 → комната освободилась, endIndex++
итог: 2 ✅
```

Максимальное значение `rooms` = максимальное число **одновременно** идущих встреч.

## ⚠️ Подводные камни именно этой задачи

1. **Начала и концы сортируются независимо.** Это выглядит «неправильно» — мы разрываем пары
   `[start, end]`. Но нам и не нужно знать, какая именно встреча закончилась; важно **сколько**
   их идёт одновременно. Осознай этот момент — он самый неинтуитивный в задаче.
2. **Касание — не конфликт.** Условие `start < end` строгое (не `<=`). Для `[[1,5],[5,8]]`
   ответ `1`, а не `2`.
3. **Компаратор обязателен** при сортировке чисел и массивов.
4. **Нельзя решать «максимум пересечений с каждым»** — это `O(N²)`.
5. Пустой массив → `0`.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение: два массива событий</summary>

```js
function minMeetingRooms(intervals) {
  if (intervals.length === 0) return 0;

  const starts = intervals.map(i => i[0]).sort((a, b) => a - b);
  const ends   = intervals.map(i => i[1]).sort((a, b) => a - b);

  let rooms = 0;
  let maxRooms = 0;
  let endIndex = 0;

  for (let i = 0; i < starts.length; i++) {
    if (starts[i] < ends[endIndex]) {
      rooms++;                       // встреча началась, свободных комнат нет
    } else {
      endIndex++;                    // одна освободилась — переиспользуем (rooms не растёт)
    }
    maxRooms = Math.max(maxRooms, rooms);
  }

  return maxRooms;
}
```

**Трассировка** `[[0,30], [5,10], [15,20]]`:
`starts = [0, 5, 15]`, `ends = [10, 20, 30]`

| i | starts[i] | ends[endIndex] | сравнение | rooms | maxRooms |
|:-:|:---------:|:--------------:|---|:-----:|:--------:|
| 0 | 0 | 10 | `0 < 10` | 1 | 1 |
| 1 | 5 | 10 | `5 < 10` | 2 | 2 |
| 2 | 15 | 10 | `15 >= 10` → endIndex = 1 | 2 | 2 |

Ответ **2** ✅

**Сложность:** время `O(N log N)` — две сортировки; память `O(N)` — два массива.

</details>

<details>
<summary>Альтернатива: sweep line (разностный массив событий)</summary>

```js
function minMeetingRoomsSweep(intervals) {
  const events = [];
  for (const [start, end] of intervals) {
    events.push([start, 1]);      // встреча началась
    events.push([end, -1]);       // встреча закончилась
  }

  // при равном времени сначала обрабатываем ОКОНЧАНИЯ (-1 < +1)
  events.sort((a, b) => a[0] - b[0] || a[1] - b[1]);

  let rooms = 0;
  let maxRooms = 0;
  for (const [, delta] of events) {
    rooms += delta;
    maxRooms = Math.max(maxRooms, rooms);
  }
  return maxRooms;
}
```

Приём «sweep line» (заметающая прямая) обобщается на массу задач: «максимум машин на дороге»,
«сколько людей в здании одновременно», «Car Pooling».

⚠️ Тонкость в компараторе: `a[0] - b[0] || a[1] - b[1]` — при одинаковом времени окончание
(`-1`) идёт раньше начала (`+1`), иначе касание `[1,5]` и `[5,8]` посчитается как пересечение.
Приём `x || y` в компараторе (сравнить по второму ключу, если первый дал `0`) стоит запомнить.

</details>
