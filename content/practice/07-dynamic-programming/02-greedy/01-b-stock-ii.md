# Best Time to Buy and Sell Stock II

**Тема:** greedy · **Сложность:** easy · **Приоритет:** 🔴 основная

В [Stock I](01-best-time-to-buy-sell-stock.md) разрешалась одна сделка. Здесь число сделок не ограничено.

## Условие

Дан массив `prices`, `prices[i]` — цена акции в день `i`. Верни максимальную прибыль от **любого числа сделок**. Одновременно можно держать не более одной акции; перед следующей покупкой предыдущую нужно продать. Можно продать и снова купить в тот же день.

`1 <= prices.length <= 10^5`, `0 <= prices[i] <= 10^4`. Сделку можно не совершать; прибыль неотрицательна.

Примеры: `[7,1,5,3,6,4] → 7`, `[1,2,3,4,5] → 4`, `[7,6,4,3,1] → 0`, `[1] → 0`.

## 🎯 Цель по сложности

Время `O(N)`, память `O(1)`.

## 🧠 Ментальная модель

Раз сделок сколько угодно, любой рост можно «нарезать» на соседние дни. Значит
ответ — **сумма всех положительных разностей соседей**.

```
цены:     7   1   5   3   6   4
разность:  -6  +4  -2  +3  -2
берём:         4       3        → 7
```

## ⚠️ Подводные камни именно этой задачи

1. **Stock II ≠ «купить на минимуме, продать на максимуме».** Проверь `[1, 5, 3, 6]`: ответ
   `4 + 3 = 7`, а не `6 - 1 = 5`.
2. **В Stock II не нужно искать пары.** Соблазн отслеживать «точку покупки» и «точку продажи»
   приводит к громоздкому коду с багами на плато. Сумма положительных разностей — короче и
   надёжнее.
3. **Массив из одного элемента** → `0` .
4. Жадное решение можно сопоставить с DP: на интервью объясни, почему локальные приросты складываются.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Stock II — решение</summary>

```js
function maxProfitMultiple(prices) {
  let profit = 0;

  for (let i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1]) {
      profit += prices[i] - prices[i - 1];      // забираем каждый рост
    }
  }

  return profit;
}
```

**Почему сумма приростов = максимум.** Любая выгодная сделка «купил в день `a`, продал в день
`b`» даёт прибыль `prices[b] - prices[a]`, что равно **сумме разностей соседних дней** на
отрезке `[a, b]`. Разбив сделку на ежедневные, мы получим ту же прибыль. При этом ежедневный
подход дополнительно позволяет **пропустить** падения, чего одна большая сделка не умеет.
Значит сумма положительных разностей не меньше любой другой стратегии.

**Трассировка** `[7, 1, 5, 3, 6, 4]`: разности `-6, +4, -2, +3, -2` → берём `4 + 3 = 7` ✅

**Сложность:** время `O(N)`, память `O(1)`.

</details>
