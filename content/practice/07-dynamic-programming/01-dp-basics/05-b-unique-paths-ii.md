# Unique Paths II — препятствия

**Тема:** dp на сетке · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

## Условие

Робот идёт из левого верхнего угла прямоугольной `obstacleGrid` в правый нижний угол, только вправо или вниз. `0` — свободная клетка, `1` — препятствие. Верни число путей, не проходящих через препятствия; заблокированные старт или финиш дают `0`. Вход не изменять.

`1 <= m, n <= 100`; ответ и промежуточные состояния помещаются в безопасное целое JS.

Примеры: `[[0,0,0],[0,1,0],[0,0,0]] → 2`, `[[1]] → 0`, `[[0]] → 1`, `[[0,1,0]] → 0`.

В [Unique Paths](05-unique-paths.md) препятствий не было.

## 🎯 Цель по сложности

Время `O(M · N)`, память `O(M · N)` таблицей и `O(N)` после оптимизации до одной строки.

## 🧠 Ментальная модель

Число путей в свободную клетку — сумма сверху и слева. Препятствие обнуляет клетку. Первая строка и столбец после препятствия могут стать недостижимыми: слепо заполнять их единицами нельзя.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>с препятствиями</summary>

```js
function uniquePathsWithObstacles(obstacleGrid) {
  const m = obstacleGrid.length;
  const n = obstacleGrid[0].length;

  if (obstacleGrid[0][0] === 1) return 0;          // старт заблокирован

  const row = new Array(n).fill(0);
  row[0] = 1;                                       // единственная стартовая клетка

  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      if (obstacleGrid[r][c] === 1) {
        row[c] = 0;                                 // сюда не дойти
      } else if (c > 0) {
        row[c] += row[c - 1];
      }
      // при c === 0 и без препятствия row[0] остаётся прежним — это путь "только вниз"
    }
  }

  return row[n - 1];
}
```

**Трассировка** для
```
[[0,0,0],
 [0,1,0],
 [0,0,0]]
```
```
r=0: [1, 1, 1]
r=1: [1, 0, 1]     ← препятствие обнулило середину
r=2: [1, 1, 2]     → ответ 2 ✅
```

Обрати внимание на строку `r=1`: обнулённая клетка «отрезала» часть путей, и это распространилось
дальше автоматически — никаких особых веток не потребовалось.

**Сложность:** время `O(m · n)`, память `O(n)`.

</details>
