# House Robber II — дома по кругу

**Тема:** dp / взять или не взять · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

## Условие

Дан массив `nums` с деньгами в домах, расположенных **по кругу**: первый и последний тоже соседи. Нельзя брать два соседних дома. Верни максимальную сумму.

`1 <= nums.length <= 100`, `0 <= nums[i] <= 400`. Для одного дома можно взять его; для двух — максимум из двух.

Примеры: `[2,3,2] → 3`, `[1,2,3,1] → 4`, `[2,1,1,2] → 3` (в линейном варианте было бы 4), `[5] → 5`.

Можно переиспользовать свою линейную функцию из [House Robber](02-house-robber.md).

## 🎯 Цель по сложности

Время `O(N)`. Версия со slice использует `O(N)` памяти; цель — `O(1)` дополнительной памяти, если передавать границы без копирования.

## 🧠 Ментальная модель

Первый и последний дом нельзя выбрать вместе. Любое допустимое решение исключает хотя бы один из них; отдельно рассмотри оба ограничения.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>House Robber II — дома по кругу (частый follow-up)</summary>

Если дома расположены **по кругу**, первый и последний тоже соседи. Приём:

```js
function robCircular(nums) {
  if (nums.length === 1) return nums[0];

  // либо не берём последний, либо не берём первый — два линейных случая
  return Math.max(
    robOptimized(nums.slice(0, -1)),
    robOptimized(nums.slice(1)),
  );
}
```

Идея: раз первый и последний нельзя взять **вместе**, достаточно решить две обычные линейные
задачи и взять лучший результат. Приём «свести круг к двум линейным случаям» встречается часто —
запомни его.


Линейный помощник из предыдущей задачи:

```js
function robOptimized(nums) {
  let skip = 0;
  let take = 0;
  for (const money of nums) {
    [skip, take] = [take, Math.max(take, skip + money)];
  }
  return take;
}
```

У этой версии `O(N)` времени и **`O(N)` памяти** из-за slice.

</details>

<details>
<summary>Версия без копирования диапазонов</summary>

```js
function robCircular(nums) {
  if (nums.length === 1) return nums[0];
  function robRange(start, end) {
    let beforePrevious = 0;
    let previous = 0;
    for (let i = start; i < end; i++) {
      [beforePrevious, previous] = [
        previous, Math.max(previous, beforePrevious + nums[i]),
      ];
    }
    return previous;
  }
  return Math.max(robRange(0, nums.length - 1), robRange(1, nums.length));
}
```

Два прохода по диапазонам: `O(N)` времени, `O(1)` дополнительной памяти.

</details>
