# House Robber

**Тема:** dp («взять или не взять») · **Сложность:** medium · **Приоритет:** 🔴 основная

> ⚠️ Разобрана в теории ([dp-basics.md](../../../07-dynamic-programming/01-dp-basics.md)).
> Пиши **по памяти**. Шаблон «взять или не взять» — самый частый переход в DP.

## Условие

Дан массив `nums`, где `nums[i]` — деньги в `i`-м доме. Дома стоят **в ряд**. Нельзя ограбить
два **соседних** дома — сработает сигнализация.

Верни максимальную сумму, которую можно унести.

## Примеры

```
Вход:  [1, 2, 3, 1]      Выход: 4     // дома 0 и 2: 1 + 3
Вход:  [2, 7, 9, 3, 1]   Выход: 12    // дома 0, 2, 4: 2 + 9 + 1
Вход:  [2, 1, 1, 2]      Выход: 4     // дома 0 и 3
Вход:  [5]               Выход: 5
```

## Ограничения

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 🎯 Цель по сложности

- Время `O(N)`, память `O(N)` таблицей и **`O(1)`** после оптимизации.

## 🧠 Ментальная модель

Смотри на **последний** дом — у него два варианта:

- **не грабим** → ответ такой же, как без него;
- **грабим** → его деньги плюс лучший результат для домов, заканчивающихся на **два** раньше.

```
dp[i] = max( dp[i-1],  nums[i-1] + dp[i-2] )
         └ пропустить    └ взять
```

⚠️ Жадность «бери самое большое» здесь **не работает**: в `[2, 1, 1, 2]` жадный алгоритм возьмёт
любую двойку и остановится с ответом `3`, тогда как оптимум `4`.

## ⚠️ Подводные камни именно этой задачи

1. **Смещение индексов.** Если `dp[i]` — «лучшее для первых `i` домов», то текущий дом это
   `nums[i - 1]`. Смешать `dp[i]` и `nums[i]` — самая частая ошибка; выбери соглашение и
   зафиксируй его комментарием.
2. **База.** `dp[0] = 0` (домов нет), `dp[1] = nums[0]`. Массив `dp` имеет длину `n + 1`.
3. **`Math.max`, а не сумма.** Задача на максимум, а не на подсчёт способов.
4. **Нельзя просто взять все чётные или все нечётные индексы.** Проверь на `[2, 1, 1, 2]`:
   чётные дают `3`, нечётные `3`, а правильный ответ `4` (дома 0 и 3 — они не соседние!).
5. **`nums.length === 1`** — вернуть единственный элемент; проверь, что код не выходит за границы.
6. Пропуск **двух и более** домов подряд разрешён — это как раз то, что ломает наивные схемы.

</details>

<summary>Подсказка 3 — O(1) памяти</summary>

Нужны только два предыдущих значения. Две переменные вместо массива.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Версия с таблицей + объяснение</summary>

```js
function rob(nums) {
  const n = nums.length;
  if (n === 0) return 0;
  if (n === 1) return nums[0];

  const dp = new Array(n + 1);      // dp[i] — лучшее для ПЕРВЫХ i домов
  dp[0] = 0;
  dp[1] = nums[0];

  for (let i = 2; i <= n; i++) {
    dp[i] = Math.max(dp[i - 1], nums[i - 1] + dp[i - 2]);
  }

  return dp[n];
}
```

**Трассировка** `[2, 1, 1, 2]` (тот самый «сложный» вход):

| i | дом `nums[i-1]` | пропустить `dp[i-1]` | взять `nums[i-1] + dp[i-2]` | dp[i] |
|:-:|:---:|:---:|:---:|:---:|
| 1 | 2 | — | — | 2 |
| 2 | 1 | 2 | 1 + 0 = 1 | **2** |
| 3 | 1 | 2 | 1 + 2 = 3 | **3** |
| 4 | 2 | 3 | 2 + 2 = 4 | **4** ✅ |

На последнем шаге видно, как алгоритм «вспомнил», что второй дом брать не стоило — именно этого
не умеет жадность.

**Сложность:** время `O(N)`, память `O(N)`.

</details>

<details>
<summary>Версия с O(1) памятью</summary>

```js
function robOptimized(nums) {
  let skip = 0;      // dp[i-2]: лучшее БЕЗ предыдущего дома
  let take = 0;      // dp[i-1]: лучшее ДО текущего дома

  for (const money of nums) {
    [skip, take] = [take, Math.max(take, skip + money)];
  }

  return take;
}
```

Одна строка в цикле делает сразу два дела: сдвигает окно и считает новый максимум.
Разберём её по шагам для ясности:

```js
const newTake = Math.max(take, skip + money);   // либо пропускаем дом, либо берём
skip = take;                                     // сдвиг окна
take = newTake;
```

Обрати внимание: эта версия не требует спецслучаев для `n === 0` и `n === 1` — цикл просто не
выполнится или выполнится один раз. Это приятный побочный эффект правильно выбранной базы.

**Сложность:** время `O(N)`, память `O(1)`.

</details>

<details>
<summary>House Robber II — дома по кругу (частый follow-up)</summary>

Если дома расположены **по кругу**, первый и последний тоже соседи. Приём:

```js
function robCircular(nums) {
  if (nums.length === 1) return nums[0];

  // либо не берём последний, либо не берём первый — два линейных случая
  return Math.max(
    robOptimized(nums.slice(0, -1)),
    robOptimized(nums.slice(1)),
  );
}
```

Идея: раз первый и последний нельзя взять **вместе**, достаточно решить две обычные линейные
задачи и взять лучший результат. Приём «свести круг к двум линейным случаям» встречается часто —
запомни его.

</details>
