# Longest Substring Without Repeating Characters

**Тема:** sliding-window (dynamic) + Set/Map · **Сложность:** medium

## Условие

Дана строка `s`. Найди **длину** самой длинной подстроки, в которой **нет повторяющихся
символов**.

Подстрока — непрерывный участок строки (символы идут подряд).

## Примеры

```
Вход:  s = "abcabcbb"
Выход: 3
Пояснение: самая длинная — "abc" (длина 3).

Вход:  s = "bbbbb"
Выход: 1
Пояснение: самая длинная — "b".

Вход:  s = "pwwkew"
Выход: 3
Пояснение: "wke" (длина 3). Обрати внимание: "pwke" — НЕ подстрока (не подряд).

Вход:  s = ""
Выход: 0
```

## Ограничения

- `0 <= s.length <= 5 * 10^4`
- `s` состоит из букв, цифр, символов и пробелов.

## 🎯 Цель по сложности

- Время: `O(N)`
- Память: `O(min(N, alphabet))` — окно хранит уникальные символы.

> ⚠️ Наивно: перебрать все подстроки и проверять уникальность → `O(N²)` или хуже.
> Sliding Window + хэш-структура → `O(N)`.

## 🧠 Ментальная модель (dynamic window)

Окно `[left .. right]` содержит подстроку **без повторов**. Расширяем `right`; если новый
символ уже есть в окне — сжимаем слева, пока дубликат не уйдёт. На каждом шаге обновляем
максимальную длину.

Есть **два подхода** — попробуй оба, если хватит сил:

1. **Set + сжатие по одному:** храни символы окна в `Set`. Пока `s[right]` уже в Set —
   удаляй `s[left]` и двигай `left++`. Потом добавь `s[right]`.
2. **Map (символ → последний индекс) + прыжок:** храни последний индекс каждого символа.
   Встретив повтор, `left` можно **перепрыгнуть** сразу за прошлую позицию этого символа
   (без пошагового сжатия). Чуть эффективнее по числу операций.

Длина окна = `right - left + 1`.

## 💡 Подсказки (открывай по очереди)

<details>
<summary>Подсказка 1 — каркас (подход Set)</summary>

`const seen = new Set(); let left = 0, best = 0;`
Внешний `for (right ...)`.
Внутренний `while (seen.has(s[right])) { seen.delete(s[left]); left++; }`
Затем `seen.add(s[right]); best = Math.max(best, right - left + 1);`

</details>

<details>
<summary>Подсказка 2 — почему сжимаем ДО добавления</summary>

Если сначала добавить `s[right]`, дубликат окажется в Set дважды по смыслу. Сначала
освобождаем место (убираем повтор слева), потом добавляем новый символ.

</details>

<details>
<summary>Подсказка 3 — подход Map с прыжком</summary>

`const last = new Map(); let left = 0, best = 0;`
Для каждого `right`: если `last.has(s[right]) && last.get(s[right]) >= left`,
то `left = last.get(s[right]) + 1`. Затем `last.set(s[right], right)` и обнови `best`.
Условие `>= left` важно — иначе прыгнёшь на старый индекс вне текущего окна.

</details>

<summary>Решение и объяснение</summary>

### Идея и инвариант

Вариант с `Set`: до добавления `s[right]` набор `seen` содержит ровно
символы окна `[left, right)`, и все они уникальны. Если новый символ уже
в наборе, удаляем символы слева, пока его старое вхождение не исчезнет.
Затем добавляем новый символ: окно `[left, right]` снова не содержит повторов.

Сжимаем только настолько, насколько необходимо, поэтому получаем самое длинное
допустимое окно с данным правым концом. `best` сохраняет максимум таких длин.
Левая граница никогда не движется назад.

### Эталонный код

```js
function lengthOfLongestSubstring(s) {
  const seen = new Set();
  let left = 0;
  let best = 0;

  for (let right = 0; right < s.length; right++) {
    while (seen.has(s[right])) {
      seen.delete(s[left]);
      left++;
    }
    seen.add(s[right]);
    best = Math.max(best, right - left + 1);
  }

  return best;
}
```

### Трассировка руками

Вход: `s = "pwwkew"`.

| `right` | Действие перед добавлением | `left` | Окно после добавления | `best` |
| --- | --- | --- | --- | --- |
| 0 (`p`) | Повтора нет | 0 | `"p"` | 1 |
| 1 (`w`) | Повтора нет | 0 | `"pw"` | 2 |
| 2 (`w`) | Удаляем `p`, но `w` ещё есть; затем удаляем старую `w` | 2 | `"w"` | 2 |
| 3 (`k`) | Повтора нет | 2 | `"wk"` | 2 |
| 4 (`e`) | Повтора нет | 2 | `"wke"` | 3 |
| 5 (`w`) — последняя итерация | Удаляем `w` с индекса `2`, затем добавляем новую | 3 | `"kew"` | 3 |

После последней итерации длина равна `5 - 3 + 1 = 3`.
Возвращаем `3`; `"pwke"` нельзя получить как непрерывное окно.

### Сложность

- Время: `O(N)` **в среднем**, при стандартном допущении `O(1)` в среднем
  для `Set.has`, `Set.add` и `Set.delete`. Каждый индекс добавляется в окно
  один раз и удаляется не более одного раза; суммарно сдвигов `left` не больше `N`.
  Один долгий `while` не делает весь алгоритм квадратичным.
  Это хэш-модель, а не обещание худшего времени `O(1)` каждой операции `Set`.
- Дополнительная память: `O(min(N, A))`, где `A` — размер алфавита:
  набор хранит только различные символы текущего окна. Если **явно считать
  алфавит фиксированным независимо от `N`**, допустима оценка `O(1)`;
  запись через `A` точнее показывает зависимость. Не следует молча принимать
  `A = 26`: здесь допустимы цифры, знаки и пробелы.
- Возвращается только длина — `O(1)` памяти результата, не копия подстроки.
  Как и обычная индексация строк JavaScript, этот код считает единицы UTF-16
  (`s[i]`, `s.length`); графемы вроде составных emoji требуют отдельно
  оговорённого контракта и другой обработки.

### Границы и типичные ошибки

- Пустая строка даёт `0`, один символ — `1`, все одинаковые — `1`,
  все разные — `s.length`. Пробел тоже обычный символ и может повторяться.
- Регистр не игнорируется: `"aA"` даёт `2`.
- Нужен `while`, не `if`: в строке `"pww"` удаление только `p` ещё не убирает повтор.
- Сначала удаляем старое вхождение, **потом** добавляем новое. `Set` не хранит
  кратность, поэтому два одинаковых символа нельзя различить внутри набора.
- Не очищай весь набор при повторе: для `"dvdf"` полезный хвост `"v"` нужен,
  чтобы найти `"vdf"` длины `3`.
- Длина включительного окна — `right - left + 1`, а последнее значение
  `right` — `s.length - 1`. Обновляй ответ после восстановления уникальности.
- В альтернативе с `Map` нельзя двигать `left` назад к старому повтору вне
  окна. На `"abba"` последнее `a` уже вне текущего окна; проверка индекса
  относительно `left` из подсказки обязательна.

</details>
