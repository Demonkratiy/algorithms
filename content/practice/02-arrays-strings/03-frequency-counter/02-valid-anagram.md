# Valid Anagram

**Тема:** frequency-counter · **Сложность:** easy

## Условие

Даны две строки `s` и `t`. Верни `true`, если `t` — **анаграмма** строки `s`, иначе `false`.

Анаграмма — строка, составленная из тех же символов в том же количестве, но, возможно, в
другом порядке. Порядок символов не важен, важен **состав** (какие символы и сколько раз).

## Примеры

```
Вход:  s = "anagram", t = "nagaram"
Выход: true

Вход:  s = "rat", t = "car"
Выход: false

Вход:  s = "a", t = "ab"
Выход: false   // разная длина
```

## Ограничения

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` и `t` состоят из строчных латинских букв.

## 🎯 Цель по сложности

- Время: `O(N)`
- Память: `O(K)` (K — число различных символов; для латиницы фактически `O(1)`).

> ⚠️ Соблазн: `s.split('').sort().join('') === t.split('').sort().join('')`. Это работает,
> но сортировка даёт `O(N log N)`. Задача проверяет именно частотный подход за `O(N)`.
> (Про sort-вариант можно упомянуть вслух как альтернативу.)

## 🧠 Ментальная модель

1. Разная длина → сразу `false` (быстрый выход + защита от «лишних» символов).
2. Посчитай частоты символов `s` в `Map` (ключ → счётчик).
3. Пройди по `t`, **вычитая** счётчики: если символа нет или счётчик уже `0` → `false`.
4. Дошёл до конца → `true`.

<summary>Решение и объяснение</summary>

### Идея и инвариант

Анаграммы имеют равные длины и одинаковые частоты каждой буквы. Сначала запасём все буквы
`s` в `Map`, затем будем расходовать по одной букве для каждого символа `t`.

Инвариант второго прохода: счётчик буквы равен её частоте в `s` минус число её вхождений
в уже обработанном префиксе `t`; все счётчики неотрицательны. Если нужного запаса нет,
строки не могут быть анаграммами. Если проход завершён, мы израсходовали ровно `s.length`
букв благодаря проверке длин. Сумма оставшихся неотрицательных счётчиков равна нулю:
все частоты совпали, отдельный проход для проверки нулей не нужен.

### Код

```js
function isAnagram(s, t) {
  if (s.length !== t.length) {
    return false;
  }

  const counts = new Map();

  for (const ch of s) {
    counts.set(ch, (counts.get(ch) ?? 0) + 1);
  }

  for (const ch of t) {
    const current = counts.get(ch) ?? 0;
    if (current === 0) {
      return false;
    }
    counts.set(ch, current - 1);
  }

  return true;
}
```

### Трассировка руками

`s = "aab"`, `t = "aba"`: начальные частоты `a → 2`, `b → 1`.
После первой `a`: `a → 1`, `b → 1`; после `b`: `a → 1`, `b → 0`;
после последней `a`: оба счётчика `0`, возвращаем `true`.
Если `t = "abb"`, последняя `b` потребует уже исчерпанный запас → `false`.

### Сложность

- `N = s.length + t.length`, `K` — число различных букв в двух строках.
- Время: `O(N)` в худшем случае при операциях `Map` за `O(1)` в среднем.
  Разные длины дают ранний выход за `O(1)`.
- Дополнительная память: `O(K)` как верхняя граница для словаря букв `s`.
  Алфавит фиксирован, `K ≤ 26`, поэтому здесь `O(1)`.
- Результат — одно логическое значение, отдельно `O(1)`; копий строк нет.

### Границы и типичные ошибки

- Одинаковые одиночные буквы → `true`; разные → `false`. Равные длины сами по себе
  недостаточны: `"aa"` и `"ab"` не анаграммы.
- Повторы существенны: сравнение через `Set` потеряет количества.
- Пустые строки вне ограничений; две пустые строки этот код сочтёт анаграммами,
  а пустую и непустую — нет.
- `Map.has(ch)` проверяет наличие ключа, не положительность счётчика. После вычитания
  ключ остаётся в `Map` со значением `0`, поэтому нужно проверять именно запас.
- `get` для отсутствующего ключа даёт `undefined`; `?? 0` позволяет одинаково обработать
  отсутствующую букву и нулевой запас.
- `counts.set(ch, current - 1)` обновляет `Map`; изменение только локальной переменной
  не обновило бы словарь. `counts[ch]` — не доступ к записи `Map`.
- `return true` нужен после **всего** прохода, а не после первого успешного вычитания.
  Для сравнения используем `===`, не `=`.
