# First Unique Character in a String

**Тема:** frequency-counter · **Сложность:** easy

## Условие
Дана строка `s` (только строчные латинские буквы). Найди **индекс первого символа, который
не повторяется** в строке. Если такого символа нет — верни `-1`.

## Примеры
```
Вход:  s = "leetcode"
Выход: 0
Пояснение: 'l' встречается один раз и стоит первым (индекс 0).

Вход:  s = "loveleetcode"
Выход: 2
Пояснение: 'l' и 'o' повторяются; первый уникальный — 'v' (индекс 2).

Вход:  s = "aabb"
Выход: -1
Пояснение: все символы повторяются.
```

## Ограничения
- `1 <= s.length <= 10^5`
- `s` состоит только из строчных латинских букв.

## 🎯 Цель по сложности
- Время: `O(N)`
- Память: `O(K)`, где K — число различных символов (≤ 26 → фактически `O(1)`).

> ⚠️ Наивно: для каждого символа пробегать всю строку и считать вхождения → `O(N²)`.
> Frequency Counter решает за `O(N)`.

## 🧠 Ментальная модель
Два прохода:
1. Первый проход — построй частотный словарь: символ → сколько раз встретился.
2. Второй проход — иди по строке **по порядку** и верни индекс первого символа, чья частота
   равна `1`.

Почему именно **два** прохода, а не один: чтобы узнать, уникален ли символ, надо сначала
увидеть **всю** строку (посчитать все частоты). Только потом можно искать первый с частотой 1.

## 💡 Подсказки (открывай по очереди)
<details>
<summary>Подсказка 1 — первый проход</summary>

`const counts = new Map();`
`for (const ch of s) counts.set(ch, (counts.get(ch) || 0) + 1);`
</details>

<details>
<summary>Подсказка 2 — второй проход</summary>

Иди по индексам: `for (let i = 0; i < s.length; i++)`.
Если `counts.get(s[i]) === 1` — верни `i`.
Дошёл до конца без находки — верни `-1`.
</details>
