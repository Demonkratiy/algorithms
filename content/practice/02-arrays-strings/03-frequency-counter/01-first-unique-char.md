# First Unique Character in a String

**Тема:** frequency-counter · **Сложность:** easy

## Условие
Дана строка `s` (только строчные латинские буквы). Найди **индекс первого символа, который
не повторяется** в строке. Если такого символа нет — верни `-1`.

## Примеры
```
Вход:  s = "leetcode"
Выход: 0
Пояснение: 'l' встречается один раз и стоит первым (индекс 0).

Вход:  s = "loveleetcode"
Выход: 2
Пояснение: 'l' и 'o' повторяются; первый уникальный — 'v' (индекс 2).

Вход:  s = "aabb"
Выход: -1
Пояснение: все символы повторяются.
```

## Ограничения
- `1 <= s.length <= 10^5`
- `s` состоит только из строчных латинских букв.

## 🎯 Цель по сложности
- Время: `O(N)`
- Память: `O(K)`, где K — число различных символов (≤ 26 → фактически `O(1)`).

> ⚠️ Наивно: для каждого символа пробегать всю строку и считать вхождения → `O(N²)`.
> Frequency Counter решает за `O(N)`.

## 🧠 Ментальная модель
Два прохода:
1. Первый проход — построй частотный словарь: символ → сколько раз встретился.
2. Второй проход — иди по строке **по порядку** и верни индекс первого символа, чья частота
   равна `1`.

Почему именно **два** прохода, а не один: чтобы узнать, уникален ли символ, надо сначала
увидеть **всю** строку (посчитать все частоты). Только потом можно искать первый с частотой 1.

<summary>Решение и объяснение</summary>

### Идея и инвариант

Сначала посчитаем **все** вхождения каждой буквы. После обработки любого префикса строки
`counts` хранит точные частоты в этом префиксе; после первого прохода — во всей строке.
Первое вхождение буквы ещё не означает, что она уникальна: повтор может оказаться в конце.

Второй проход идёт по индексам слева направо. Перед проверкой индекса `i` среди индексов
меньше `i` уникальных букв нет. Поэтому первая найденная частота `1` даёт именно первый
подходящий индекс. Если проверены все индексы, ответа нет.

### Код

```js
function firstUniqChar(s) {
  const counts = new Map();

  for (const ch of s) {
    counts.set(ch, (counts.get(ch) ?? 0) + 1);
  }

  for (let i = 0; i < s.length; i++) {
    if (counts.get(s[i]) === 1) {
      return i;
    }
  }

  return -1;
}
```

### Трассировка руками

Для `"aab"` после первого прохода: `a → 2`, `b → 1`.
Второй проход: `i = 0` → пропускаем `a`; `i = 1` → пропускаем `a`;
**последняя итерация** `i = 2` → возвращаем `2`.
Для `"aabb"` второй проход закончится без возврата из цикла, затем вернётся `-1`.

### Сложность

- `N` — длина `s`, `K` — число различных букв.
- Время: `O(N)` — два линейных прохода, а не два вложенных цикла.
- Дополнительная память: `O(K)` для `Map`. Здесь `K ≤ 26`, поэтому `O(1)`.
- Результат — одно число, `O(1)` памяти отдельно от словаря; вход не копируется.

Операции `Map` оцениваем как `O(1)` в среднем. Индексы JavaScript подходят условию:
каждая строчная латинская буква занимает одну кодовую единицу строки.

### Границы и типичные ошибки

- Одна буква → `0`; все буквы повторяются → `-1`; уникальная только в конце → последний индекс.
- Пустая строка не входит в ограничения; этот код вернёт для неё `-1`.
- `counts.get(ch)` для отсутствующего ключа даёт `undefined`; прибавление без `?? 0`
  дало бы `NaN`.
- У `Map` нужны `get` и `set`: `counts[ch]` не читает запись словаря.
- `for...of` перебирает символы, а второй цикл — индексы. Возвращать нужно индекс,
  не букву и не частоту.
- Граница цикла — `i < s.length`, проверка — `=== 1`, а не присваивание `= 1`.
  `return -1` стоит **после** цикла, иначе поиск оборвётся на первой повторяющейся букве.
