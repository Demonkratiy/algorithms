# Top K Frequent Elements

**Тема:** frequency-counter (+ сортировка / bucket) · **Сложность:** medium

## Условие

Дан массив чисел `nums` и число `k`. Верни `k` **самых часто встречающихся** элементов.
Порядок в ответе — любой.

Гарантируется, что ответ единственный (частоты позволяют однозначно выбрать top-k).

## Примеры

```
Вход:  nums = [1, 1, 1, 2, 2, 3], k = 2
Выход: [1, 2]

Вход:  nums = [1], k = 1
Выход: [1]

Вход:  nums = [4, 4, 4, 6, 6, 7, 7, 7, 7], k = 1
Выход: [7]
```

## Ограничения

- `1 <= nums.length <= 10^5`
- `k` в диапазоне `[1, число различных элементов]`

## 🎯 Цель по сложности

- Приемлемо: `O(N log N)` (счётчик + сортировка по частоте).
- Продвинуто: `O(N)` через **bucket sort** (корзины по частоте). Про этот способ можно
  рассказать вслух как оптимизацию.

## 🧠 Ментальная модель

Шаг 1 (Frequency Counter) — посчитай частоты: `Map` `число → сколько раз`.
Шаг 2 — выбери `k` ключей с наибольшими частотами.

Два способа шага 2:

1. **Сортировка** (проще): взять пары `[число, частота]`, отсортировать по частоте убыв.,
   взять первые `k` чисел. Это `O(M log M)`, где M — число различных элементов.
2. **Bucket sort** (`O(N)`): завести массив `buckets`, где индекс = частота, значение =
   список чисел с такой частотой. Частота не превышает `N`, поэтому индексов достаточно.
   Пройти корзины с конца (от высокой частоты к низкой) и набрать `k` чисел.

Начни со способа 1 (сортировка). Способ 2 — назови как оптимизацию до `O(N)`.

## 💡 Подсказки (открывай по очереди)

<details>
<summary>Подсказка 1 — частоты</summary>

`const counts = new Map();`
`for (const n of nums) counts.set(n, (counts.get(n) || 0) + 1);`

</details>

<details>
<summary>Подсказка 2 — сортировка пар</summary>

`const entries = [...counts];` // массив пар [число, частота]
`entries.sort((a, b) => b[1] - a[1]);` // по частоте убыв.
Возьми первые `k`: `entries.slice(0, k).map(pair => pair[0]);`

</details>

<details>
<summary>Подсказка 3 — про сравнение в sort</summary>

`sort((a, b) => b[1] - a[1])` сортирует по убыванию частоты. `a[1]`/`b[1]` — это частоты
(второй элемент пары). Если перепутать знак — получишь возрастание.

</details>
