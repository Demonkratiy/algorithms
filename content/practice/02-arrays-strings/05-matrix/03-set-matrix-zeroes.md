# Set Matrix Zeroes

**Тема:** matrix · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

> ⚠️ Разобрана в теории ([matrix.md](../../../02-arrays-strings/05-matrix.md)).
> Пиши **по памяти**. Главный урок задачи универсален: **нельзя менять данные, по которым ещё
> принимаешь решения.**

## Условие

Дана матрица `m × n`. Если элемент равен `0`, обнули **всю его строку и весь его столбец**.
Сделай это **на месте**.

## Примеры

```
Вход:  [[1,1,1],        Выход: [[1,0,1],
        [1,0,1],                [0,0,0],
        [1,1,1]]                [1,0,1]]

Вход:  [[0,1,2,0],      Выход: [[0,0,0,0],
        [3,4,5,2],              [0,4,5,0],
        [1,3,1,5]]              [0,3,1,0]]
```

## Ограничения

- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1` (то есть «магическое значение-маркер» использовать нельзя —
  любое число может встретиться в данных)

## 🎯 Цель по сложности

| Подход | Время | Память |
|---|:---:|:---:|
| Копия матрицы | `O(m·n)` | `O(m·n)` |
| Два `Set` (строки и столбцы) | `O(m·n)` | `O(m + n)` |
| **Флаги в самой матрице** | `O(m·n)` | **`O(1)`** ← цель |

## 🧠 Ментальная модель

**Почему нельзя обнулять сразу.** Поставленный ноль неотличим от исходного, и следующая итерация
воспримет его как повод обнулить ещё одну строку. Цепная реакция обнулит всю матрицу.

Поэтому решение всегда двухфазное: **сначала собрать информацию, потом применить**.

Для `O(1)` памяти хранилищем флагов служат **первая строка и первый столбец** самой матрицы:
`matrix[r][0] = 0` означает «строку `r` надо обнулить», `matrix[0][c] = 0` — «столбец `c`».
Единственная проблема — их собственное состояние: клетка `matrix[0][0]` относится сразу и к
строке, и к столбцу. Её запоминаем отдельными булевыми флагами.

## ⚠️ Подводные камни именно этой задачи

1. **Обнуление «на лету»** — главная ловушка. Обязательно два прохода.
2. **Первая строка и первый столбец обрабатываются ПОСЛЕДНИМИ.** Пока они хранят флаги, трогать
   их нельзя. Порядок здесь — суть решения.
3. **Циклы применения флагов начинаются с `r = 1, c = 1`.** Если начать с нуля, флаг сам себя
   «применит» и испортит хранилище.
4. **Два отдельных флага** для первой строки и первого столбца. Одного не хватит: `matrix[0][0]`
   принадлежит обоим, и по нему нельзя различить эти случаи. Проверь на `[[0,1],[1,1]]` и
   `[[1,1],[0,1]]` — ответы разные.
5. **Маркер-значение не подойдёт.** Соблазн ставить `-Infinity` или `null` вместо нуля разбивается
   об ограничения: в матрице могут быть любые числа, а менять тип элемента — грязный хак.
6. Матрица может быть прямоугольной: `rows` и `cols` считаем отдельно.

</details>

<details>
<summary>Подсказка 2 — идея O(1)</summary>

Где можно хранить `m + n` флагов, не выделяя память? Внутри самой матрицы — в первой строке и
первом столбце.

</details>

<details>
<summary>Подсказка 3 — что запомнить отдельно</summary>

Два булевых значения: «была ли изначально нулевая клетка в первой строке» и «в первом столбце».

</details>

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Версия с O(m + n) памяти (промежуточная)</summary>

```js
function setZeroesSets(matrix) {
  const zeroRows = new Set();
  const zeroCols = new Set();

  for (let r = 0; r < matrix.length; r++) {
    for (let c = 0; c < matrix[0].length; c++) {
      if (matrix[r][c] === 0) {
        zeroRows.add(r);
        zeroCols.add(c);
      }
    }
  }

  for (let r = 0; r < matrix.length; r++) {
    for (let c = 0; c < matrix[0].length; c++) {
      if (zeroRows.has(r) || zeroCols.has(c)) matrix[r][c] = 0;
    }
  }
}
```

Полностью корректно, `O(m·n)` время и `O(m + n)` память. Это нормальный первый ответ на
интервью — с него и начинай, а `O(1)` предлагай как оптимизацию.

</details>

<details>
<summary>Версия с O(1) памяти + объяснение</summary>

```js
function setZeroes(matrix) {
  const rows = matrix.length;
  const cols = matrix[0].length;

  let firstRowHasZero = false;
  let firstColHasZero = false;

  for (let c = 0; c < cols; c++) {
    if (matrix[0][c] === 0) firstRowHasZero = true;
  }
  for (let r = 0; r < rows; r++) {
    if (matrix[r][0] === 0) firstColHasZero = true;
  }

  // фаза 1: расставляем флаги в первой строке и первом столбце
  for (let r = 1; r < rows; r++) {
    for (let c = 1; c < cols; c++) {
      if (matrix[r][c] === 0) {
        matrix[r][0] = 0;
        matrix[0][c] = 0;
      }
    }
  }

  // фаза 2: применяем флаги (начиная с 1, чтобы не затереть хранилище)
  for (let r = 1; r < rows; r++) {
    for (let c = 1; c < cols; c++) {
      if (matrix[r][0] === 0 || matrix[0][c] === 0) matrix[r][c] = 0;
    }
  }

  // фаза 3: и только теперь — сами первая строка и первый столбец
  if (firstRowHasZero) {
    for (let c = 0; c < cols; c++) matrix[0][c] = 0;
  }
  if (firstColHasZero) {
    for (let r = 0; r < rows; r++) matrix[r][0] = 0;
  }
}
```

**Трассировка** `[[0,1,2,0],[3,4,5,2],[1,3,1,5]]`:

- предварительно: `firstRowHasZero = true` (есть нули в строке 0), `firstColHasZero = true`
  (`matrix[0][0] === 0`);
- фаза 1: во внутренней области (`r,c >= 1`) нулей нет → флаги не меняются, но в первой строке
  уже стоят нули на позициях 0 и 3 из исходных данных;
- фаза 2: обнуляются клетки, у которых `matrix[0][c] === 0` → столбцы 0 и 3;
- фаза 3: полностью обнуляются первая строка и первый столбец.

Результат:
```
0 0 0 0
0 4 5 0
0 3 1 0    ✅
```

**Почему нужны ДВА флага.** Клетка `matrix[0][0]` — общая для первой строки и первого столбца.
Если бы флаг был один, случаи «ноль был только в первой строке» и «только в первом столбце»
стали бы неразличимы. Проверь на `[[1,0],[1,1]]`: обнулиться должен только столбец 1, а первая
колонка остаться нетронутой.

**Сложность:** время `O(m · n)` — четыре прохода, каждый линейный. Память `O(1)` — два булевых
значения.

</details>
