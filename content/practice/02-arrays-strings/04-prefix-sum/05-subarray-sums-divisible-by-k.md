# Subarray Sums Divisible by K

**Тема:** prefix-sum + hash map (остатки) · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

> Продолжение «Subarray Sum Equals K». Тот же скелет, но ключ в `Map` — **остаток** от деления.
> Хороший индикатор того, что ты понял паттерн, а не заучил код.

## Условие

Дан массив целых чисел `nums` и целое `k`. Верни количество непрерывных подмассивов, сумма
которых **делится на `k`** (сумма `0` тоже делится).

## Примеры

```
Вход:  nums = [4, 5, 0, -2, -3, 1], k = 5
Выход: 7
// [4,5,0,-2,-3,1], [5], [5,0], [5,0,-2,-3], [0], [0,-2,-3], [-2,-3]

Вход:  nums = [5], k = 9
Выход: 0
```

## Ограничения

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `2 <= k <= 10^4`

## 🎯 Цель по сложности

- Время **`O(N)`**, память **`O(K)`** (различных остатков не больше `k`).

## 🧠 Ментальная модель

Сумма подмассива `[l..r]` = `prefix[r] - prefix[l-1]`. Она делится на `k` ровно тогда, когда
`prefix[r]` и `prefix[l-1]` дают **одинаковый остаток** при делении на `k`.

Значит: копим префиксную сумму, берём её остаток, и считаем, **сколько раз такой же остаток уже
встречался** — столько подмассивов и заканчивается в текущей позиции.

Это тот же алгоритм, что в задаче 02, только вместо «искать сумму `sum - k`» мы «ищем
одинаковый остаток».

## ⚠️ Подводные камни именно этой задачи

1. **Отрицательный остаток в JS.** `-1 % 5` даёт `-1`, а не `4`. Из-за этого одинаковые по сути
   остатки попадут в разные ключи `Map` и ответ будет занижен.
   Нормализация: `((sum % k) + k) % k`. Это **главная ловушка задачи** — знай её наизусть.
2. **Стартовый `{0: 1}`** нужен по той же причине, что и раньше: подмассив с начала массива.
3. Считаем **сколько пар**, а не «есть ли». Прибавляем к ответу значение счётчика, потом
   увеличиваем счётчик на 1.
4. Не путай с задачей «есть ли подмассив длины ≥ 2 с суммой, кратной k» — там дополнительно
   хранят **индекс** первого появления остатка, а не количество.

## 💡 Подсказки (открывай по очереди)

<details>
<summary>Подсказка 1 — что класть в Map</summary>

Ключ — нормализованный остаток `((sum % k) + k) % k`, значение — сколько раз встречался.
Инициализация: `map.set(0, 1)`.

</details>

<details>
<summary>Подсказка 2 — почему одинаковые остатки</summary>

Если `prefix[r] % k === prefix[l-1] % k`, то их разность делится на `k` без остатка.
А разность префиксов — это и есть сумма подмассива.

</details>

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение + объяснение</summary>

```js
function subarraysDivByK(nums, k) {
  const remainderCounts = new Map();
  remainderCounts.set(0, 1);

  let sum = 0;
  let result = 0;

  for (const num of nums) {
    sum += num;
    const remainder = ((sum % k) + k) % k;                 // нормализуем отрицательный остаток
    result += remainderCounts.get(remainder) || 0;
    remainderCounts.set(remainder, (remainderCounts.get(remainder) || 0) + 1);
  }

  return result;
}
```

**Трассировка** `nums = [4, 5, 0, -2, -3, 1]`, `k = 5`:

| num | sum | remainder | нашли в Map | result | map после |
|:---:|:---:|:---------:|:-----------:|:------:|-----------|
| — | 0 | — | — | 0 | `{0:1}` |
| 4 | 4 | 4 | 0 | 0 | `{0:1, 4:1}` |
| 5 | 9 | 4 | 1 | 1 | `{0:1, 4:2}` |
| 0 | 9 | 4 | 2 | 3 | `{0:1, 4:3}` |
| -2 | 7 | 2 | 0 | 3 | `{0:1, 4:3, 2:1}` |
| -3 | 4 | 4 | 3 | 6 | `{0:1, 4:4, 2:1}` |
| 1 | 5 | 0 | 1 | 7 | `{0:2, 4:4, 2:1}` |

Ответ **7** ✅

**Сложность:** время `O(N)`, память `O(K)` — различных остатков не больше `k`.

</details>

<details>
<summary>Что будет без нормализации остатка</summary>

На шаге `sum = -2 % 5` JS вернёт `-2`, тогда как математически остаток равен `3`. Префиксы с
остатками `-2` и `3` — это на самом деле один и тот же класс, но в `Map` они лягут под разные
ключи, и часть подмассивов не будет посчитана. Проверь на `nums = [-1, 2, 9]`, `k = 2`:
правильный ответ `2`, без нормализации получится меньше.

</details>
