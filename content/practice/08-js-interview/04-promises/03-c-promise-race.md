# Свой Promise.race

**Тема:** js-interview / async · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

Самостоятельное продолжение [Promise.all](03-promise-all.md). Вход — плотный конечный массив промисов, thenable или обычных значений; исходные операции не отменяются. Соответствующий встроенный комбинатор вызывать нельзя.

## Условие

Реализуй `myRace(promises)`: результат определяется **первым завершившимся** входом — значение или причина ошибки. Пустой массив оставляет промис в `pending` навсегда. Обычные значения нормализуются через промисы.

`myRace([Promise.resolve(1), 2]) → 1`; первая ранняя ошибка должна отклонить результат, а не ждать успеха других входов.

## 🎯 Цель по сложности

Подписка на `N` входов: `O(N)` работы и `O(N)` памяти обработчиков; локальное состояние `O(1)`. Wall-clock ожидание — до первого завершения (или бесконечно на пустом входе).

## 🧠 Ментальная модель

Первый resolve/reject фиксирует состояние результирующего промиса; следующие ничего не меняют.

## ⚠️ Подводные камни именно этой задачи

Не путай race с any: ошибка тоже побеждает. Пустой массив не выполняется с []. Все входы должны получить обработчик ошибки, включая проигравших.

Подпиши resolve и reject общего промиса на каждый нормализованный вход; отдельный счётчик завершений не нужен.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение</summary>

```js
function myRace(promises) {
  return new Promise((resolve, reject) => {
    for (const item of promises) {
      Promise.resolve(item).then(resolve, reject);    // кто первый — тот и победил
    }
  });
}
```

.then(resolve, reject) подписывается на всех, а результат определит первый завершившийся. Остальные операции не отменяются.

</details>

<details>
<summary>Таблица различий (часто спрашивают устно)</summary>

| Комбинатор | Когда резолвится | Когда реджектится | Результат |
|---|---|---|---|
| `all` | все успешны | **первая** ошибка | массив значений |
| `allSettled` | все завершились | никогда | массив `{status, value/reason}` |
| `race` | первый **завершившийся** | если первый завершился ошибкой | значение/ошибка первого |
| `any` | первый **успешный** | все отклонены | значение первого успешного / `AggregateError` |

Мнемоника: `all` — «все или ничего», `allSettled` — «расскажи про всех», `race` — «кто первый»,
`any` — «первый, у кого получилось».

Практика: `all` — параллельная загрузка обязательных данных; `allSettled` — когда часть
запросов может падать (дашборд с виджетами); `race` — таймаут запроса
(`race([fetch(...), timeout(5000)])`); `any` — запрос к нескольким зеркалам.

</details>
