# sleep — неблокирующая пауза

**Тема:** js-interview / async · **Сложность:** medium · **Приоритет:** 🔴 основная

Три популярные утилиты промисов и таймеров теперь решаются отдельно: sleep, [withTimeout](01-b-with-timeout.md), [retry](01-c-retry.md). Все нужны в прикладном коде.

## Условие

Реализуй `sleep(ms)`: верни промис, выполняющийся значением `undefined` **не раньше** чем через `ms` миллисекунд. Пауза не должна блокировать поток; при `ms = 0` выполнение тоже асинхронное. `ms` — конечное неотрицательное число в допустимом диапазоне таймера.

```js
await sleep(1000);
console.log('прошла секунда');
```

## 🎯 Цель по сложности

Синхронная работа `O(1)`, дополнительная память `O(1)` на вызов. Wall-clock ожидание зависит от `ms` и занятости Event Loop; точное время таймер не гарантирует.

## 🧠 Ментальная модель

**sleep** оборачивает колбэчный API `setTimeout` в промис. Это уместное применение `new Promise`; конструктор не нужен для простого переоборачивания уже существующего промиса.

## ⚠️ Подводные камни именно этой задачи

Цикл `while (Date.now() - start < ms) {}` блокирует поток: нет рендера и обработки событий. Нельзя вызывать resolve сразу при создании таймера.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>sleep — решение</summary>

```js
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
```

**Почему `new Promise` здесь уместен.** Обычно оборачивать что-то в `new Promise` — антипаттерн,
но `setTimeout` — колбэчный API, у которого нет промис-версии. Это как раз тот случай, для
которого конструктор и предназначен.

Проверка на «неблокирующесть»:
```js
sleep(1000).then(() => console.log('готово'));
console.log('это выведется сразу');       // сначала эта строка
```

⚠️ Блокирующий вариант, который **нельзя** предлагать:
```js
function badSleep(ms) {
  const end = Date.now() + ms;
  while (Date.now() < end) {}     // вешает вкладку: ни рендера, ни событий
}
```

</details>

<details>
<summary>Как проверить себя офлайн</summary>

```js
// sleep не блокирует
const t0 = Date.now();
sleep(300).then(() => console.log('sleep:', Date.now() - t0, 'мс'));   // ~300
console.log('строка сразу после sleep');                                // печатается ПЕРВОЙ
```

</details>
