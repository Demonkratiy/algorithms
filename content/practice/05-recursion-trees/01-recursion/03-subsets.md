# Subsets (все подмножества) — backtracking

**Тема:** recursion / backtracking · **Сложность:** medium · **Приоритет:** 🔴 основная

> Эталонная задача на **перебор с возвратом**. Освоив шаблон, ты получишь ключ к целому классу
> задач: комбинации, перестановки, расстановки, генерация скобок, судоку.

## Условие

Дан массив **уникальных** чисел `nums`. Верни **все возможные подмножества** (power set).

Порядок подмножеств и элементов внутри них — любой. Дубликатов в ответе быть не должно.

## Примеры

```
Вход:  [1, 2, 3]
Выход: [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]     (8 = 2³ подмножеств)

Вход:  [0]
Выход: [[], [0]]

Вход:  []
Выход: [[]]           ← пустое множество имеет ровно одно подмножество
```

## Ограничения

- `1 <= nums.length <= 10`
- все элементы уникальны.

## 🎯 Цель по сложности

- Время **`O(N · 2^N)`** — подмножеств `2^N`, копирование каждого стоит до `O(N)`.
- Память `O(N)` на стек рекурсии + `O(N · 2^N)` на сам ответ.
- Экспонента здесь **неизбежна**: ответ сам по себе экспоненциального размера.
  Это важно проговорить, чтобы не выглядело, будто решение «неоптимально».

## 🧠 Ментальная модель

Для каждого элемента есть **два решения**: включить его в подмножество или нет.
Дерево решений:

```
                    []
          вкл 1 /        \ не вкл 1
             [1]              []
        /        \        /       \
     [1,2]       [1]    [2]       []
      / \        / \    / \       / \
 [1,2,3][1,2] [1,3][1] [2,3][2] [3]  []
```

`2^N` листьев = `2^N` подмножеств. Обход дерева — это и есть рекурсия.

### Шаблон backtracking

```js
function backtrack(startIndex, path) {
  result.push([...path]);          // КОПИЯ текущего состояния

  for (let i = startIndex; i < nums.length; i++) {
    path.push(nums[i]);            // 1. выбрали
    backtrack(i + 1, path);        // 2. рекурсия для оставшихся
    path.pop();                    // 3. ОТКАТИЛИ выбор
  }
}
```

Три строки «выбрали → рекурсия → откатили» — сердце паттерна. Запомни их как единый блок.

## ⚠️ Подводные камни именно этой задачи

1. **`result.push([...path])`, а не `result.push(path)`.** `path` — один и тот же массив,
   который постоянно мутируется. Без копии в ответе окажется `2^N` ссылок на один массив,
   который в конце работы пуст. **Ошибка №1 во всех задачах на перебор.**
2. **`path.pop()` обязателен.** Без него состояние «протекает» между ветками дерева, и
   подмножества получаются мусорными.
3. **`backtrack(i + 1, ...)`, а не `backtrack(startIndex + 1, ...)`.** Передавать надо `i + 1`
   — «продолжаем с элемента, следующего за только что выбранным». С `startIndex + 1` получишь
   неверный набор.
4. **Пустое подмножество тоже ответ.** Строка `result.push([...path])` стоит **до** цикла и
   без условий — на первом же вызове она добавит `[]`.
5. **Нет отдельного базового случая** — это нормально! Рекурсия остановится сама, когда
   `startIndex === nums.length` и цикл `for` не выполнится ни разу. Многие ищут `if (...) return`
   и путаются — здесь он не нужен.

## 💡 Подсказки (открывай по очереди)

<details>
<summary>Подсказка 1 — что такое startIndex</summary>

Индекс, с которого можно выбирать элементы. Он не даёт брать уже использованные и
предотвращает дубликаты вроде `[1,2]` и `[2,1]` (для подмножеств порядок неважен).

</details>

<details>
<summary>Подсказка 2 — куда положить push результата</summary>

**В начало** функции, до цикла: каждое состояние `path` — само по себе валидное подмножество.

</details>

<details>
<summary>Подсказка 3 — альтернативный способ (итеративный)</summary>

Начни с `[[]]`. Для каждого числа: к каждому уже имеющемуся подмножеству добавь копию с этим
числом. Размер результата удваивается на каждом элементе — отсюда `2^N`.

</details>

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение (backtracking) + объяснение</summary>

```js
function subsets(nums) {
  const result = [];
  const path = [];

  function backtrack(startIndex) {
    result.push([...path]);                 // копия текущего состояния

    for (let i = startIndex; i < nums.length; i++) {
      path.push(nums[i]);                   // выбрали nums[i]
      backtrack(i + 1);                     // продолжаем с СЛЕДУЮЩЕГО за i
      path.pop();                           // откатили выбор
    }
  }

  backtrack(0);
  return result;
}
```

**Пошаговый разбор** для `nums = [1, 2, 3]`:

| вызов | path при входе | что добавили в result |
|---|---|---|
| `backtrack(0)` | `[]` | `[]` |
| ↳ `backtrack(1)` после push(1) | `[1]` | `[1]` |
| ↳↳ `backtrack(2)` после push(2) | `[1,2]` | `[1,2]` |
| ↳↳↳ `backtrack(3)` после push(3) | `[1,2,3]` | `[1,2,3]` |
| откат до `[1]`, push(3) → `backtrack(3)` | `[1,3]` | `[1,3]` |
| откат до `[]`, push(2) → `backtrack(2)` | `[2]` | `[2]` |
| ↳ push(3) → `backtrack(3)` | `[2,3]` | `[2,3]` |
| откат до `[]`, push(3) → `backtrack(3)` | `[3]` | `[3]` |

Итого 8 подмножеств = `2³` ✅

**Сложность:** время `O(N · 2^N)` — `2^N` вызовов, в каждом копирование `path` до `O(N)`.
Память: `O(N)` глубина рекурсии + `O(N · 2^N)` на результат (он от нас не зависит).

</details>

<details>
<summary>Итеративное решение (полезно знать)</summary>

```js
function subsetsIterative(nums) {
  let result = [[]];

  for (const num of nums) {
    const withNum = result.map(subset => [...subset, num]);
    result = [...result, ...withNum];        // размер удваивается
  }

  return result;
}
```

**Трассировка** `[1, 2, 3]`:
```
старт:  [[]]
после 1: [[], [1]]
после 2: [[], [1], [2], [1,2]]
после 3: [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

Удвоение на каждом шаге наглядно объясняет, откуда берётся `2^N`. Та же сложность, но без
рекурсии — иногда проще для объяснения.

</details>

<details>
<summary>Шаблон backtracking — используй его, а не запоминай задачу</summary>

```js
function backtrack(state) {
  if (/* решение готово */) {
    result.push([...path]);      // КОПИЯ
    return;                       // если нужен явный выход
  }

  for (const choice of /* доступные варианты */) {
    if (/* вариант невалиден */) continue;   // отсечение (pruning)

    path.push(choice);            // выбрали
    backtrack(/* новое состояние */);
    path.pop();                   // откатили
  }
}
```

**Задачи этого семейства** (меняются только «доступные варианты» и условие готовности):
- Subsets / Subsets II (с дубликатами — нужна сортировка + пропуск повторов);
- Permutations / Permutations II — см. [`04-permutations`](04-permutations.md);
- Combination Sum, Combinations;
- Generate Parentheses;
- Word Search, N-Queens, Sudoku Solver (там же появляется **pruning** — отсечение заведомо
  неудачных веток, что критично для производительности).

Маркер в условии: **«все возможные…»**, «сгенерировать все варианты», «сколькими способами».

</details>
