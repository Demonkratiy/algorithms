# Deep Get — значение по вложенному пути

**Тема:** вложенные данные / линейный проход · **Сложность:** easy · **Приоритет:** ⚪ дополнительная

## Условие

Достань значение по строковому пути, безопасно возвращая `undefined`, если путь оборвался.

```
deepGet({ a: { b: { c: 42 } } }, 'a.b.c')    → 42
deepGet({ a: { b: {} } }, 'a.b.c')           → undefined
deepGet({}, 'a.b.c')                          → undefined
```

`path` — непустая строка непустых ключей, разделённых точками; экранирование точек и синтаксис скобок не требуются. На промежуточном `null`/`undefined` верни `undefined`; значение `null` в самом конце пути возвращается как есть. Обычный доступ к свойствам, без вызова функций; вход не изменять.

## 🎯 Цель по сложности

Время `O(L + K)`, память `O(L + K)` на разбиение пути, где `L` — длина пути, `K` — число ключей. Сам проход использует `O(1)` рабочего состояния.

## 🧠 Ментальная модель

Здесь нет ветвления: каждый ключ задаёт единственный следующий шаг. Работа с вложенными данными не обязательно требует рекурсии.

## ⚠️ Подводные камни именно этой задачи

`typeof null` — `"object"`, поэтому такой проверки недостаточно. `0`, `false` и пустая строка — допустимые значения; не путай их с отсутствием.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>deepGet</summary>

```js
function deepGet(obj, path) {
  const keys = path.split('.');

  let current = obj;
  for (const key of keys) {
    if (current == null) return undefined;    // == ловит и null, и undefined
    current = current[key];
  }

  return current;
}
```

Здесь рекурсия не нужна — цикла достаточно. **Это важный вывод:** не всякая работа с вложенной
структурой требует рекурсии. Рекурсия нужна, когда ветвление **заранее неизвестно** (много
потомков), а не когда путь линейный.

Рекурсивный вариант для сравнения:
```js
function deepGetRecursive(obj, path) {
  if (obj == null) return undefined;

  const [head, ...rest] = Array.isArray(path) ? path : path.split('.');
  if (rest.length === 0) return obj[head];

  return deepGetRecursive(obj[head], rest);
}
```

`current == null` с **двойным** равенством — редкий случай, когда `==` уместен и является
идиомой: он проверяет одновременно `null` и `undefined`. В остальных случаях используй `===`.


**Сложность:** итеративный вариант — `O(L + K)` времени и памяти на split. Рекурсивная альтернатива копирует `rest` на каждом шаге: до `O(L + K²)` времени и удерживаемой памяти, стек `O(K)`.

</details>
