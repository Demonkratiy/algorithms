# Reverse String — рекурсивный разворот строки

**Тема:** recursion (база + шаг) · **Сложность:** easy · **Приоритет:** 🔴 основная

Самостоятельная разминка после [Power](02-power-and-reverse.md).

## Условие

Разверни строку **рекурсивно**. `split('').reverse().join('')` использовать нельзя.

```
reverseString("hello") = "olleh"
reverseString("a")     = "a"
reverseString("")      = ""
```

Для этой разминки вход — ASCII-строка, чтобы не смешивать рекурсию с Unicode. Не изменяй внешний объект и не используй встроенный reverse.

## 🎯 Цель по сложности

Для версии со slice и конкатенацией при копировании строк: время `O(N²)`, стек `O(N)`, суммарная память удерживаемых подстрок до `O(N²)`. Версия через массив — `O(N)` времени и памяти. Не обещай линейную память на основании одной только глубины стека.

## 🧠 Ментальная модель

**Рекурсивный контракт.** Не раскручивай стек в голове. Спроси себя:

1. Какой вход **тривиален** и ответ известен сразу? → база.
2. Если вложенный вызов **уже вернул правильный ответ** для меньшего входа, что мне сделать,
   чтобы получить ответ для текущего? → шаг.

Для `reverseString`: если `reverse("ello")` уже равно `"olle"`, то `reverse("hello")` — это
`"olle" + "h"`. База: пустая строка (или строка из одного символа).

## ⚠️ Подводные камни именно этой задачи

1. Забытый `return` перед рекурсивным вызовом даёт `undefined`.
2. **Конкатенация строк в рекурсии — `O(N²)`.** В JS строки неизменяемы: каждая операция `+`
   создаёт **новую** строку длины `k`, а таких операций `N`. На интервью это стоит проговорить:
   «версия через массив и join была бы O(N)».
3. `reverseString("")` — обязательная проверка базы. Глубокая рекурсия может переполнить стек.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>reverseString</summary>

```js
function reverseString(str) {
  if (str.length <= 1) return str;                     // база: "" и "a"
  return reverseString(str.slice(1)) + str[0];         // хвост развёрнут + первый символ
}
```

**Как читать:** `reverseString("hello")` = `reverseString("ello") + "h"`.
Доверяем контракту: вложенный вызов вернёт `"olle"`, значит результат `"olle" + "h"` = `"olleh"` ✅

**Сложность:** глубина рекурсии `O(N)`; но каждая конкатенация создаёт новую строку длиной до
`N` символов → суммарно `O(N²)` по времени и памяти. Это честный ответ, который стоит озвучить.

Эффективная (нерекурсивная) версия:
```js
function reverseStringFast(str) {
  const chars = [...str];
  let left = 0;
  let right = chars.length - 1;
  while (left < right) {
    [chars[left], chars[right]] = [chars[right], chars[left]];
    left++;
    right--;
  }
  return chars.join('');
}
```
`O(N)` время. Узнаёшь? Это **Two Pointers** — тот же приём, что в
[Valid Palindrome](../../02-arrays-strings/01-two-pointers/01-valid-palindrome.md).

</details>

<details>
<summary>Что здесь тренируется (не пропусти)</summary>

Эта задача и [Power](02-power-and-reverse.md) — про **формулировку контракта**. Прежде чем писать код, произнеси вслух:

> «Если вложенный вызов правильно решает задачу для входа поменьше, то я делаю _вот это_,
> чтобы получить ответ для своего входа. А самый маленький вход — _вот такой_, и ответ на него
> — _вот такой_».

Если ты можешь произнести эти две фразы — код напишется сам. Если не можешь — код не поможет.
Именно этот навык понадобится в задачах на деревья, где рекурсия становится основным
инструментом.

</details>
