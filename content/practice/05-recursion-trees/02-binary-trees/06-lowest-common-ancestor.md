# Lowest Common Ancestor — Binary Search Tree

**Тема:** binary-trees / BST · **Сложность:** easy · **Приоритет:** ⚪ дополнительная

## Условие

Дано **binary search tree** с корнем `root`. Верни наименьшего общего предка двух **узлов** `p` и `q`: самый глубокий узел, являющийся предком обоих. Узел — предок самого себя. Возвращай исходный узел по ссылке, не значение.

`2 <= N <= 10^5`, значения уникальны, `p !== q`, оба узла присутствуют. Поля узла: `{ val, left, right }`, отсутствующие потомки — `null`.

```
        6                    BST:
      /   \                    LCA(2, 8) = 6
     2     8                   LCA(2, 4) = 2   ← узел является предком самого себя
    / \   / \
   0   4 7   9
      / \
     3   5
```

Для дерева без свойства BST — [отдельная задача](06-b-lowest-common-ancestor-binary-tree.md).

## 🎯 Цель по сложности

Время `O(H)`, память `O(1)` при итеративном решении. В сбалансированном BST `H = O(log N)`, в вырожденном `H = O(N)`.

## 🧠 Ментальная модель

**используем свойство BST.** Начиная с корня:
- если **оба** значения меньше текущего → LCA точно в левом поддереве;
- если **оба** больше → в правом;
- иначе (значения «разошлись» или одно равно текущему) → **текущий узел и есть LCA**.

Точка расхождения — это и есть ответ. Спускаться дальше не нужно.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>LCA в BST — решение</summary>

```js
function lowestCommonAncestorBST(root, p, q) {
  let node = root;

  while (node !== null) {
    if (p.val < node.val && q.val < node.val) {
      node = node.left;                 // оба слева
    } else if (p.val > node.val && q.val > node.val) {
      node = node.right;                // оба справа
    } else {
      return node;                      // разошлись (или один совпал) → LCA
    }
  }

  return null;
}
```

**Трассировка** `LCA(2, 8)` в BST из примера:
- узел `6`: `2 < 6`, но `8 > 6` → разошлись → **вернуть 6** ✅

**Трассировка** `LCA(2, 4)`:
- узел `6`: оба (`2`, `4`) меньше `6` → идём влево;
- узел `2`: `p.val === node.val` → ни одно из условий не выполнено → **вернуть 2** ✅
  (узел — предок самого себя).

**Сложность:** время `O(h)` — спускаемся по одному пути; `O(log N)` для сбалансированного BST.
Память `O(1)` — итеративно, без рекурсии.

</details>
