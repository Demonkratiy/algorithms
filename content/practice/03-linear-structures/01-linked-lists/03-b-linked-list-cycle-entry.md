# Linked List Cycle II — вход в цикл

**Тема:** linked-lists (Floyd) · **Сложность:** medium · **Приоритет:** 🔴 основная

Сначала реши [обнаружение цикла](03-linked-list-cycle.md). Здесь нужен узел, а не `boolean`.

## Условие

Дан `head` односвязного списка. Верни **сам узел**, с которого начинается цикл, либо `null`, если цикла нет. Список изменять нельзя; значения могут повторяться.

Примеры: `3 → 2 → 0 → -4`, где `-4.next` ссылается на узел `2`, → этот узел `2`; `1 → 2 → null` → `null`; один узел со ссылкой на себя → этот узел; пустой список → `null`.

`0 <= N <= 10^4`.

## 🎯 Цель по сложности

Время `O(N)`, дополнительная память `O(1)`. Вариант с `Set` требует `O(N)` памяти и допустим как первый подход.

## 🧠 Ментальная модель

Обозначим: `F` — расстояние от головы до входа в цикл, `a` — расстояние от входа до места
встречи, `C` — длина цикла.

В момент встречи: `slow` прошёл `F + a`, `fast` прошёл `2(F + a)`, и разница — целое число
кругов: `2(F + a) - (F + a) = F + a = k·C`.

Отсюда `F = k·C - a`. То есть **расстояние от головы до входа в цикл равно расстоянию от места
встречи до входа** (с точностью до целых кругов).

Практический вывод: после встречи ставим один указатель обратно в `head`, второй оставляем в
точке встречи, двигаем **оба по одному шагу** — они встретятся ровно во входе в цикл.

## ⚠️ Подводные камни именно этой задачи

Сравнивай **ссылки**, а не значения. Проверяй `fast` и `fast.next` до продвижения. На первом этапе проверяй встречу после шага. На втором этапе **оба** указателя двигаются по одному узлу. Не помечай и не разрывай узлы.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>detectCycle — решение</summary>

```js
function detectCycle(head) {
  let slow = head;
  let fast = head;

  while (fast !== null && fast.next !== null) {
    slow = slow.next;
    fast = fast.next.next;

    if (slow === fast) {                 // встретились внутри цикла
      let p = head;
      while (p !== slow) {               // оба по ОДНОМУ шагу
        p = p.next;
        slow = slow.next;
      }
      return p;                          // точка входа в цикл
    }
  }

  return null;
}
```

**Почему второй этап работает** — см. вывод в разделе «Ментальная модель»: `F = k·C - a`,
поэтому пройдя `F` шагов от головы и `F` шагов от точки встречи, оба указателя окажутся во
входе в цикл.

Проверь руками на `3 → 2 → 0 → -4`, где `-4.next = 2`:

| итерация | slow | fast |
|:---:|:---:|:---:|
| старт | 3 | 3 |
| 1 | 2 | 0 |
| 2 | 0 | 2 |
| 3 | -4 | -4 → **встреча** |

Дальше `p = 3`, `slow = -4`. Один шаг: `p = 2`, `slow = 2` → **равны**, ответ — тот самый узел `2` ✅

</details>
