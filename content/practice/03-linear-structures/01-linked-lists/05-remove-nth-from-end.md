# Remove Nth Node From End of List

**Тема:** linked-lists (два указателя с зазором + dummy) · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

## Условие

Дан `head` списка и число `n`. Удали `n`-й узел **с конца** и верни голову списка.

Требование: **один проход**.

## Примеры

```
Вход:  1 → 2 → 3 → 4 → 5,  n = 2
Выход: 1 → 2 → 3 → 5

Вход:  1,  n = 1
Выход: null

Вход:  1 → 2,  n = 2      // удаляем ГОЛОВУ
Выход: 2
```

## Ограничения

- `1 <= n <= число узлов <= 30`
- `n` всегда валиден.

## 🎯 Цель по сложности

- Время `O(N)` за **один** проход, память `O(1)`.
- Двухпроходный вариант (посчитать длину, потом дойти до `length - n`) — рабочий, но менее
  ценный ответ.

## 🧠 Ментальная модель

**Зазор между указателями.** Разгоняем `fast` на `n` шагов вперёд, затем двигаем `fast` и `slow`
синхронно. Когда `fast` упрётся в конец, между `slow` и концом останется ровно `n` узлов.

```
n = 2
1 → 2 → 3 → 4 → 5 → null
s       f                 ← зазор 2
...двигаем оба...
1 → 2 → 3 → 4 → 5 → null
        s           f     ← slow перед удаляемым (4), если стартовать от dummy
```

Чтобы удалить узел в односвязном списке, нужно стоять на **предыдущем**: `prev.next = prev.next.next`.
Поэтому `slow` стартует с `dummy`, а не с `head`.

## ⚠️ Подводные камни именно этой задачи

1. **Удаление головы** (`n === длине списка`). Без dummy нужен отдельный `if` → лишний баг.
   С `dummy` этот случай обрабатывается тем же кодом. Это **главный смысл** задачи.
2. **На сколько разгонять `fast`: `n` или `n + 1`?** Зависит от того, откуда стартует `slow`.
   Если оба от `dummy` — разгон на `n + 1`; если `fast` от `head`, а `slow` от `dummy` — на `n`.
   Не заучивай: **проверь на примере из 2 узлов**, это займёт 20 секунд и снимет вопрос.
3. **Условие второго цикла — `while (fast !== null)`**, а не `fast.next`. Ошибка здесь сдвигает
   всё на один узел (классический off-by-one).
4. **Возвращать `dummy.next`, а не `head`** — иначе при удалении головы вернёшь удалённый узел.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение + объяснение</summary>

```js
function removeNthFromEnd(head, n) {
  const dummy = new ListNode(0, head);
  let slow = dummy;
  let fast = dummy;

  for (let i = 0; i <= n; i++) {     // n + 1 шаг: оба стартовали с dummy
    fast = fast.next;
  }

  while (fast !== null) {            // двигаем синхронно до конца
    slow = slow.next;
    fast = fast.next;
  }

  slow.next = slow.next.next;        // slow стоит ПЕРЕД удаляемым
  return dummy.next;
}
```

**Проверка «сколько шагов разгона» на списке из 2 узлов**, `n = 2` (удаляем голову):

- `dummy → 1 → 2 → null`
- разгон на `n + 1 = 3` шага: `fast`: dummy → 1 → 2 → `null`
- второй цикл не выполняется (`fast === null`), `slow` остался на `dummy`
- `slow.next = slow.next.next` → `dummy.next = 2`
- возвращаем `dummy.next = 2` ✅ — голова удалена без единой дополнительной ветки.

**Трассировка** `1→2→3→4→5`, `n = 2`:

| этап | slow | fast |
|---|:---:|:---:|
| после разгона (3 шага) | dummy | 3 |
| синхронно | 1 | 4 |
| синхронно | 2 | 5 |
| синхронно | 3 | null → стоп |

`slow = 3`, удаляем `slow.next = 4` → `1→2→3→5` ✅

**Сложность:** время `O(N)` — один проход (разгон + синхронное движение вместе дают ≤ `N` шагов
для `fast`), память `O(1)`.

</details>

<details>
<summary>Двухпроходный вариант (запасной)</summary>

```js
function removeNthFromEndTwoPass(head, n) {
  const dummy = new ListNode(0, head);

  let length = 0;
  for (let node = head; node; node = node.next) length++;

  let prev = dummy;
  for (let i = 0; i < length - n; i++) prev = prev.next;   // встаём перед удаляемым

  prev.next = prev.next.next;
  return dummy.next;
}
```

Тоже `O(N)`/`O(1)`, проще для рассуждений. Если на интервью растерялся — напиши сначала его,
а потом скажи: _«могу свести к одному проходу через два указателя с зазором n»_.

</details>
