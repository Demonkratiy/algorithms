# Palindrome Linked List

**Тема:** linked-lists (середина + разворот) · **Сложность:** medium · **Приоритет:** ⚪ дополнительная

> Задача-«сборка»: соединяет три уже изученных приёма — fast/slow, разворот и two pointers.
> Отличный финальный тест по теме.

## Условие

Дан `head` односвязного списка. Верни `true`, если последовательность значений — палиндром
(читается одинаково с обеих сторон), иначе `false`.

Цель: время `O(N)`, память **`O(1)`**.

## Примеры

```
Вход:  1 → 2 → 2 → 1       Выход: true
Вход:  1 → 2 → 3 → 2 → 1   Выход: true
Вход:  1 → 2               Выход: false
Вход:  1                   Выход: true
```

## Ограничения

- `1 <= n <= 10^5`
- `0 <= Node.val <= 9`

## 🎯 Цель по сложности

- Наивно: скопировать значения в массив, сравнить два указателя. Время `O(N)`, память `O(N)`.
- Цель: время `O(N)`, память **`O(1)`** — без копирования.

## 🧠 Ментальная модель

Три шага:

1. **Найти середину** (fast/slow) — конец первой половины.
2. **Развернуть вторую половину** — теперь у нас есть два списка, идущих «навстречу» смыслу:
   первая половина слева направо, развёрнутая вторая — тоже слева направо, но это бывший конец.
3. **Сравнить поэлементно**, пока вторая половина не кончится.

```
1 → 2 → 3 → 2 → 1
       ↑ середина
первая:  1 → 2 → 3
вторая:  1 → 2   (развёрнутая из 2 → 1)
сравниваем 1 vs 1, 2 vs 2 → true
```

## ⚠️ Подводные камни именно этой задачи

1. **Нечётная длина.** Средний элемент не с кем сравнивать — и не нужно. Поэтому цикл сравнения
   идёт **пока не кончится вторая (более короткая) половина**, а не первая. Условие
   `while (second !== null)` — а не `while (first && second)` из осторожности.
2. **Какую середину брать.** Здесь удобнее **конец первой половины**
   (`while (fast.next && fast.next.next)`), чтобы разворачивать ровно хвост.
3. **Разрушение входного списка.** Разворот меняет исходную структуру. На интервью это стоит
   проговорить: _«я модифицирую список; если нужно — восстановлю его обратным разворотом»_.
   Некоторые интервьюеры специально спрашивают про это.
4. **`O(1)` памяти достигается только без массива.** Версия с массивом корректна, но не решает
   поставленную задачу — озвучь её как наивную и оптимизируй.
5. Списки длины 1 и 2 — обязательные проверки; на них чаще всего ломается деление пополам.

## 🔍 Разбор — открывай ТОЛЬКО после своей попытки

<details>
<summary>Решение + объяснение</summary>

```js
function isPalindrome(head) {
  if (head === null || head.next === null) return true;

  // 1. конец первой половины
  let slow = head;
  let fast = head;
  while (fast.next !== null && fast.next.next !== null) {
    slow = slow.next;
    fast = fast.next.next;
  }

  // 2. разворот второй половины
  let prev = null;
  let curr = slow.next;
  while (curr !== null) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }

  // 3. сравнение
  let first = head;
  let second = prev;                 // голова развёрнутой второй половины
  while (second !== null) {          // вторая половина короче или равна — по ней и идём
    if (first.val !== second.val) return false;
    first = first.next;
    second = second.next;
  }

  return true;
}
```

**Трассировка** `1 → 2 → 3 → 2 → 1` (нечётная длина):

- поиск: `slow` останавливается на узле `3` (конец первой половины: `1→2→3`);
- вторая половина `2→1` разворачивается в `1→2`;
- сравнение: `first=1` vs `second=1` ✅, `first=2` vs `second=2` ✅, `second` стал `null` → `true`.

Средний узел `3` не участвует в сравнении — и правильно, у палиндрома нечётной длины центр
всегда «сам себе пара».

**Трассировка** `1 → 2` (чётная, не палиндром):

- цикл поиска не выполняется (`fast.next.next === null`), `slow = 1`;
- вторая половина `2` разворачивается в `2`;
- сравнение `1 !== 2` → `false` ✅

**Сложность:** время `O(N)` (поиск `N/2` + разворот `N/2` + сравнение `N/2`),
память `O(1)`.

</details>

<details>
<summary>Наивная версия с массивом (назвать первой на интервью)</summary>

```js
function isPalindromeArray(head) {
  const vals = [];
  for (let node = head; node; node = node.next) vals.push(node.val);

  let l = 0;
  let r = vals.length - 1;
  while (l < r) {
    if (vals[l] !== vals[r]) return false;
    l++;
    r--;
  }
  return true;
}
```

Время `O(N)`, память `O(N)`. Это буквально задача
[Valid Palindrome](../../02-arrays-strings/01-two-pointers/01-valid-palindrome.md), которую ты уже решал — узнаёшь
паттерн Two Pointers? Ценность «списочной» версии именно в `O(1)` памяти.

</details>

<summary>Бонус: восстановить список</summary>

пришей обратно: `slow.next = reverse(prev);`. Стоит упомянуть даже если не просят — показывает
