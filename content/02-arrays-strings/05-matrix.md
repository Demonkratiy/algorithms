# Matrix / 2D Arrays (матрицы)

## 🎯 Идея

Матрица — массив массивов. Отдельного «алгоритма матриц» не существует: это **набор приёмов
работы с двумя индексами**, где почти все ошибки — от путаницы `row`/`col` и границ.

Отдельная тема нужна ровно по одной причине: **типовые ловушки здесь свои**, и знание трёх-четырёх
приёмов закрывает почти все задачи этого класса.

```js
const grid = [
  [1, 2, 3],
  [4, 5, 6],
];

const rows = grid.length;        // 2 — количество СТРОК
const cols = grid[0].length;     // 3 — количество СТОЛБЦОВ
grid[r][c];                      // сначала строка, потом столбец
```

## 🧠 Приёмы, которые надо знать

### 1. Создание матрицы (главная ловушка JS)

```js
// ❌ НЕПРАВИЛЬНО — m ссылок на ОДНУ строку
const bad = new Array(m).fill(new Array(n).fill(0));
bad[0][0] = 1;
bad[1][0];        // 1 — изменились все строки!

// ✅ ПРАВИЛЬНО
const good = Array.from({ length: m }, () => new Array(n).fill(0));
```

Та же ошибка встречается в графах (`fill([])` для списков смежности) — запомни её один раз.

### 2. Обход в четырёх направлениях

```js
const directions = [[-1, 0], [1, 0], [0, -1], [0, 1]];      // вверх, вниз, влево, вправо
// с диагоналями — добавить [[-1,-1], [-1,1], [1,-1], [1,1]]

for (const [dr, dc] of directions) {
  const nr = r + dr;
  const nc = c + dc;
  if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;   // ОДНА проверка на все
  // ...
}
```

### 3. Транспонирование + разворот = поворот

Поворот матрицы на 90° по часовой стрелке = **транспонировать**, затем **развернуть каждую
строку**:

```
1 2 3      транспонируем     1 4 7     разворачиваем строки    7 4 1
4 5 6      ───────────────→  2 5 8     ───────────────────→    8 5 2
7 8 9                        3 6 9                             9 6 3
```

Против часовой стрелки — наоборот: сначала развернуть строки, потом транспонировать.

```js
// транспонирование на месте: только ВЕРХНИЙ треугольник (c начинается с r + 1)
for (let r = 0; r < n; r++) {
  for (let c = r + 1; c < n; c++) {
    [matrix[r][c], matrix[c][r]] = [matrix[c][r], matrix[r][c]];
  }
}
```

> ⚠️ Если писать `c = 0`, каждая пара поменяется **дважды** — матрица вернётся в исходное
> состояние. Это классическая ошибка; условие `c > r` обязательно.

### 4. Одномерный индекс ↔ двумерный

Иногда матрицу удобно рассматривать как плоский массив (например, для `Set` посещённых или
бинарного поиска по отсортированной матрице):

```js
const index = r * cols + c;
const r = Math.floor(index / cols);
const c = index % cols;
```

### 5. Границы как «слои»

Спиральный обход и повороты удобно описывать четырьмя границами, которые сходятся к центру:

```js
let top = 0, bottom = rows - 1, left = 0, right = cols - 1;
while (top <= bottom && left <= right) {
  // пройти верхнюю строку, правый столбец, нижнюю строку, левый столбец
  // сдвинуть границы внутрь
}
```

## ⏱️ Сложность

- Любой полный обход — **`O(m · n)`**; это нижняя граница для задач, где нужно посмотреть все
  клетки.
- Память `O(1)`, если работаем **на месте**; `O(m · n)` — если создаём копию или `visited`.
- ⚠️ Не пиши `O(N²)`, если матрица прямоугольная: правильно **`O(m · n)`**. `N²` уместно только
  для квадратной, и то лучше уточнить.

## 📝 Эталонный разбор: Set Matrix Zeroes

Если элемент матрицы равен `0`, обнулить **всю его строку и весь столбец**. Сделать это
**на месте**.

```
[[1,1,1],        [[1,0,1],
 [1,0,1],   →     [0,0,0],
 [1,1,1]]         [1,0,1]]
```

### Ход мысли

**Наивно:** обходить и обнулять сразу → **неверно**: новые нули запустят обнуление ещё не
просмотренных строк, и вся матрица станет нулевой. Классическая ловушка: **нельзя менять данные,
по которым ещё принимаешь решения.**

**Первое исправление:** запомнить в двух `Set` номера строк и столбцов, которые надо обнулить,
и сделать это вторым проходом. `O(m + n)` памяти — уже верно.

**Оптимизация до `O(1)`:** использовать **первую строку и первый столбец самой матрицы** как
хранилище флагов. Единственная тонкость — их собственное состояние надо запомнить отдельно.

### Решение (O(1) памяти)
```js
function setZeroes(matrix) {
  const rows = matrix.length;
  const cols = matrix[0].length;

  let firstRowHasZero = false;
  let firstColHasZero = false;

  for (let c = 0; c < cols; c++) if (matrix[0][c] === 0) firstRowHasZero = true;
  for (let r = 0; r < rows; r++) if (matrix[r][0] === 0) firstColHasZero = true;

  // ставим флаги в первой строке/столбце
  for (let r = 1; r < rows; r++) {
    for (let c = 1; c < cols; c++) {
      if (matrix[r][c] === 0) {
        matrix[r][0] = 0;
        matrix[0][c] = 0;
      }
    }
  }

  // применяем флаги — со ВТОРОЙ строки и столбца
  for (let r = 1; r < rows; r++) {
    for (let c = 1; c < cols; c++) {
      if (matrix[r][0] === 0 || matrix[0][c] === 0) matrix[r][c] = 0;
    }
  }

  // и только теперь — сами первая строка и первый столбец
  if (firstRowHasZero) for (let c = 0; c < cols; c++) matrix[0][c] = 0;
  if (firstColHasZero) for (let r = 0; r < rows; r++) matrix[r][0] = 0;
}
```

**Почему первая строка/столбец обрабатываются последними.** Они служат хранилищем флагов; если
обнулить их раньше, флаги для остальных клеток будут потеряны. Порядок здесь — и есть решение
задачи.

**Сложность:** время `O(m · n)`, память `O(1)`.

## ⚠️ Частые ошибки / чек-лист

- ❌ **`new Array(m).fill(new Array(n))`** — общая строка для всех.
- ❌ **Путать `matrix[r][c]` и `matrix[c][r]`.** Договорись с собой: **первый индекс — строка**.
  В именах используй `r`/`c` или `row`/`col`, а не `i`/`j`.
- ❌ **`matrix.length` — это строки, `matrix[0].length` — столбцы.** Для прямоугольной матрицы
  перепутать = выйти за границы.
- ❌ **Транспонирование по всей матрице** вместо верхнего треугольника — двойной обмен.
- ❌ **Модифицировать матрицу во время принятия решений** (Set Matrix Zeroes).
- ❌ **Пустая матрица** `[]` или `[[]]` — проверяй `matrix.length === 0 || matrix[0].length === 0`.
- ❌ Писать `O(N²)` вместо `O(m · n)` для прямоугольной матрицы.
- ✅ Всегда сохраняй `rows` и `cols` в переменные в начале — короче и меньше ошибок.

## ✅ Мини-опрос для самопроверки

1. Почему `new Array(3).fill(new Array(3).fill(0))` — ошибка, и как правильно?
2. Как повернуть матрицу на 90° по часовой стрелке через две простые операции?
3. Почему при транспонировании на месте внутренний цикл начинается с `r + 1`?
4. Что не так с решением «обходим матрицу и сразу обнуляем строки и столбцы»?
5. Как записать сложность обхода прямоугольной матрицы и почему не `O(N²)`?
6. Как перевести пару `(r, c)` в одномерный индекс и обратно?

<details>
<summary>Ответы</summary>

1. `fill` кладёт **одну и ту же ссылку** во все ячейки, поэтому все строки — это один массив, и
   изменение в одной видно во всех. Правильно: `Array.from({length: m}, () => new Array(n).fill(0))`.
2. Транспонировать (отразить относительно главной диагонали), затем развернуть каждую строку.
   Для поворота против часовой — сначала развернуть строки, потом транспонировать.
3. Чтобы каждая пара `(r, c)` и `(c, r)` менялась **ровно один раз**. При `c = 0` пара
   поменяется дважды, и матрица вернётся в исходное состояние.
4. Мы модифицируем данные, по которым ещё принимаем решения: свежепоставленные нули будут
   восприняты как «исходные» и обнулят лишние строки — в итоге вся матрица станет нулевой.
   Нужно сначала собрать информацию, потом применить.
5. **`O(m · n)`** — размеры независимы. `O(N²)` подразумевает `m === n`, что верно только для
   квадратной матрицы; для прямоугольной это неправильная оценка.
6. `index = r * cols + c`; обратно `r = Math.floor(index / cols)`, `c = index % cols`.
   Приём нужен для `Set` посещённых клеток и для бинарного поиска по «плоской» матрице.

</details>
