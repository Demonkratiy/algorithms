# Структуры данных JS изнутри (Array / Object / Map / Set)

## 🎯 Идея

Правильный выбор структуры данных — половина решения задачи. Главный секрет большинства
оптимизаций: **`Map`, `Set` и обращение по ключу к объекту работают за `O(1)`**. Это позволяет
заменять медленные поиски (`O(N)`) на мгновенные и убирать вложенные циклы.

> 📌 Если ты понял только одну вещь из этой заметки — пусть это будет:
> **поиск/вставка/удаление по ключу в `Map`/`Set`/`Object` = `O(1)`, а `arr.includes(x)` = `O(N)`.**

---

## 🧠 Ментальная модель

- **Array** — это пронумерованные ячейки в памяти подряд. Знаешь индекс → мгновенно попал в
  ячейку (`arr[i]` = `O(1)`). Но чтобы **найти значение** без индекса — нужно перебирать (`O(N)`).
- **Хэш-таблица** (`Object`, `Map`, `Set`) — «умный словарь». Ключ прогоняется через
  хэш-функцию, которая сразу указывает ячейку. Поэтому доступ по ключу — `O(1)`, независимо от
  размера. Платим за это тем, что **порядок и индексы не работают как в массиве**.

## 📚 Разбор структур

### 1. `Array` — упорядоченный список
```js
const arr = [10, 20, 30];
arr[1];              // O(1) — доступ по индексу
arr.push(40);        // O(1) — добавить в конец
arr.pop();           // O(1) — удалить с конца
arr.unshift(5);      // O(N) ⚠️ — вставить в начало (сдвигает ВСЕ элементы)
arr.shift();         // O(N) ⚠️ — удалить с начала (сдвигает ВСЕ элементы)
arr.includes(20);    // O(N) ⚠️ — поиск значения (перебор)
arr.indexOf(20);     // O(N) ⚠️
```
> ⚠️ **Ключевая ловушка:** `push`/`pop` (конец) — быстрые `O(1)`, а `shift`/`unshift`
> (начало) — медленные `O(N)`, потому что все элементы переиндексируются.

### 2. `Object` — хэш-таблица со строковыми ключами
```js
const obj = {};
obj['apple'] = 5;    // O(1) — вставка
obj['apple'];        // O(1) — доступ
'apple' in obj;      // O(1) — проверка наличия ключа
delete obj['apple']; // O(1) — удаление
```
> ⚠️ Ключи объекта **всегда приводятся к строке**: `obj[1]` и `obj['1']` — один и тот же ключ.
> Порядок ключей не гарантирован для целочисленно-подобных ключей.

### 3. `Map` — хэш-таблица с ключами любого типа
```js
const map = new Map();
map.set('a', 1);     // O(1)
map.set(42, 'x');    // ключ-число (не строка!)
map.get('a');        // O(1)
map.has('a');        // O(1)
map.delete('a');     // O(1)
map.size;            // O(1) — размер сразу известен
for (const [k, v] of map) { }  // сохраняет порядок вставки
```
> ✅ Предпочитай `Map` вместо `Object`, когда: ключи не строки; важен порядок вставки;
> часто нужен размер (`.size`); ключи задаются динамически.

### 4. `Set` — коллекция уникальных значений
```js
const set = new Set();
set.add(1);          // O(1)
set.add(1);          // дубликат игнорируется → {1}
set.has(1);          // O(1) — мгновенная проверка наличия
set.delete(1);       // O(1)
set.size;            // O(1)

// Частый приём — убрать дубликаты из массива:
const unique = [...new Set([1, 1, 2, 3, 3])];  // [1, 2, 3]
```

## ⏱️ Таблица сложностей операций

| Операция                     | Array          | Object | Map  | Set  |
|------------------------------|----------------|--------|------|------|
| Доступ по индексу/ключу      | `O(1)`         | `O(1)` | `O(1)` | —  |
| Поиск значения               | `O(N)`         | `O(1)`* | `O(1)`* | `O(1)` |
| Вставка                      | `O(1)` в конец / `O(N)` в начало | `O(1)` | `O(1)` | `O(1)` |
| Удаление                     | `O(1)` с конца / `O(N)` из начала/середины | `O(1)` | `O(1)` | `O(1)` |

\* Для `Object`/`Map`/`Set` «поиск» — это проверка наличия ключа/значения (`in`, `.has`), а не
поиск по произвольному значению. Найти ключ **по значению** — по-прежнему `O(N)`.

## 📝 Эталонный разбор: как Set убирает вложенный цикл

**Задача:** есть ли в массиве два одинаковых числа? (`containsDuplicate`)

### Наивное решение — O(N²)
```js
function containsDuplicate(nums) {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] === nums[j]) return true;   // сравниваем каждую пару
    }
  }
  return false;
}
```
**Ход мысли:** мы сравниваем каждый элемент с каждым — вложенный цикл, `O(N²)`. При `N = 100000`
это 10 млрд операций. Слишком медленно.

### Оптимизация — O(N) через Set
```js
function containsDuplicate(nums) {
  const seen = new Set();          // "память" о том, что уже видели
  for (const num of nums) {        // один проход — O(N)
    if (seen.has(num)) return true; // O(1) проверка
    seen.add(num);                  // O(1) вставка
  }
  return false;
}
```
**Ход мысли (ключевая ментальная модель!):** _«Вложенный цикл нужен, чтобы вспомнить, что я
уже встречал. А что, если запоминать увиденное в `Set`? Тогда проверка "видел ли раньше"
станет `O(1)`, и второй цикл не нужен»._

**Итог:** время `O(N²) → O(N)`, память `O(1) → O(N)`. Это тот самый размен «память ↔ скорость».
Этот приём — основа десятков интервью-задач.

## ⚠️ Частые ошибки / чек-лист

- ❌ Использовать `arr.includes(x)` внутри цикла → скрытый `O(N²)`. Заменяй на `Set`.
- ❌ Использовать `shift()`/`unshift()` в горячем цикле → `O(N)` на операцию. Для очереди
  бери индекс-указатель или структуру-очередь.
- ❌ Хранить числовые ключи в `Object` и удивляться приведению к строке. Бери `Map`.
- ✅ Нужна «была ли уже» / «уникальность» → `Set`.
- ✅ Нужен «счётчик / словарь ключ→значение» → `Map` (или `Object`).
- ✅ Всегда помни: `push`/`pop` — быстрые, `shift`/`unshift` — медленные.
