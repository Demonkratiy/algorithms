# Binary Trees (DFS / BFS)

> _Скелет заметки._

## 🎯 Идея
Узел + левый/правый потомок. Обходы: DFS (pre/in/post-order) и BFS (по уровням).

## 🧠 Как распознать
Иерархия, «обойти дерево», глубина/высота, поиск пути. Аналогия — DOM / Virtual DOM.

## ⏱️ Сложность
Обход `O(N)`; память DFS — высота дерева, BFS — ширина уровня.
