# Linked Lists (связные списки)

> _Скелет заметки._

## 🎯 Идея
Узел = значение + ссылка на следующий. Нет индексов, доступ последовательный.

## 🧠 Как распознать
Разворот списка, поиск цикла, средний элемент, слияние отсортированных списков.

## ⏱️ Сложность
Доступ/поиск `O(N)`, вставка/удаление при известном узле `O(1)`.
