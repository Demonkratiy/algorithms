# Контекст проекта

Эта папка хранит согласованные решения и актуальное состояние разработки, а не логи
работы агента. Прочитай её перед изменением приложения.

## Порядок чтения

1. [Статус](status.md) — что существует сейчас и что ещё не согласовано.
2. [Решения](decisions.md) — договорённости с владельцем и их причины.
3. [Архитектура](architecture.md) — целевая структура и границы ответственности.

Для учебного занятия дополнительно смотри [прогресс](../personal/PROGRESS.md) и
[правила обучения](../.github/copilot-instructions.md).

## Как поддерживать контекст

- Отделяй принятые решения от предложений и открытых вопросов.
- Обновляй документы при изменении соответствующих договорённостей или реализации.
- Удаляй устаревшие утверждения; не дописывай бесконечную историю действий.
- Проверенные технические наблюдения записывай с условиями воспроизведения.
- Не дублируй учебный прогресс, команды запуска и подробности, уже описанные в другом
  документе: используй ссылки.
- Не сохраняй секреты, персональные данные посетителей, временные логи и переписку.
- Документы не заменяют код и тесты. Статус «работает» должен опираться на проверку.

Эти файлы входят в репозиторий и не являются приватным хранилищем.
