# Valid Palindrome

**Тема:** two-pointers · **Сложность:** easy

## Условие

Дана строка `s`. Определи, является ли она **палиндромом**, учитывая только
буквы и цифры и игнорируя регистр.

Палиндром — строка, которая читается одинаково слева направо и справа налево.

Правила очистки:

- Все НЕ буквенно-цифровые символы (пробелы, запятые, двоеточия и т.п.) игнорируются.
- Регистр не важен: `A` и `a` считаются одинаковыми.

Верни `true`, если строка — палиндром, иначе `false`.

## Примеры

```
Вход:  "A man, a plan, a canal: Panama"
Выход: true
Пояснение: после очистки → "amanaplanacanalpanama" — палиндром.

Вход:  "race a car"
Выход: false
Пояснение: после очистки → "raceacar" — не палиндром.

Вход:  " "
Выход: true
Пояснение: после очистки → "" (пустая строка) считается палиндромом.
```

## Ограничения

- `1 <= s.length <= 2 * 10^5`
- `s` состоит из печатаемых ASCII-символов.

## 🎯 Цель по сложности (к чему стремиться)

- Время: `O(N)`
- Память: `O(1)` — постарайся решить **без создания новой очищенной строки**,
  двигая два указателя прямо по исходной строке. (Сначала можно решить как угодно,
  потом оптимизируем до O(1) памяти.)

## 💡 Подсказки (открывай по очереди, только если застрял)

<details>
<summary>Подсказка 1 — какой паттерн</summary>

Два указателя навстречу: `left` с начала, `right` с конца.

</details>

<details>
<summary>Подсказка 2 — как игнорировать лишние символы</summary>

Если символ под `left` не буква/цифра — двигай `left++` и не сравнивай.
Аналогично для `right--`. Пропускай «мусор», прежде чем сравнивать.

</details>

<details>
<summary>Подсказка 3 — как проверить, что символ буква/цифра</summary>

Можно регуляркой `/[a-z0-9]/i` или сравнением кодов символов через `charCodeAt`.
Регистр приводи через `.toLowerCase()` при сравнении.

</details>

## ✍️ Моё решение

```js
function isPalindrome(s) {
  // пиши здесь
  let left = 0;
  let right = s.length - 1;
  function isAlphaNumeric(char) {
    return /[a-z0-9]/i.test(char); //true if char is valid letter or number
  }
  while (left < right) {
    //добавить проверку на корректность символов
    while (left < right && !isAlphaNumeric(s[left])) left++;
    while (left < right && !isAlphaNumeric(s[right])) right--;
    if (s[left].toLowerCase() === s[right].toLowerCase()) {
      left++;
      right--;
    } else {
      return false;
    }
  }
  return true;
}
```

## 🧮 Моя оценка сложности

Время: O(n) · Память: O(1)
